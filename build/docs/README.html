AEGIS — Cyber Training System

A private, self-hosted cyber training environment for Kali Linux. Runs entirely on your own machine,
no cloud, no tracking, no build step, works offline.

┌─ AEGIS ───────────────────────────────────────────────────────┐
│  9 gated tiers · 32 courses · 182 lectures · 405 concepts     │
│  Every lecture: video + full study notes + Kali field lab     │
│  Gamified: merit points, agency ranks, commendations, streaks │
│  Progress is git-versioned in this private repo                │
└───────────────────────────────────────────────────────────────┘

Run it

./run.sh              # http://localhost:8420
./run.sh --lan        # also reachable from your phone on the LAN

Layout

data/          source of truth (hand-editable YAML)
  tiers.yml      the 9-tier ladder, ranks, XP economy, domains
  badges.yml     23 commendations and their unlock rules
  concepts.yml   405 knowledge-graph nodes with cross-links
  courses/*.yml  32 courses, 182 lectures
notes/         the study notes you actually read (Markdown)
docs/          rules of engagement, prerequisites, lab range setup
progress/      YOUR progress — committed, so it is also a study timeline
tools/         build, validate, lab runner, prerequisite + shell checks
site/          the app (plain HTML/CSS/JS, no framework)
transcripts/   local lecture captions (git-ignored)

Tools

Command Purpose
python3 tools/build.py YAML + Markdown → site/build/
python3 tools/validate.py schema + integrity check (run before every launch)
python3 tools/check_shell_blocks.py verify every lab's shell is runnable
python3 tools/check_prereqs.py which tools the labs need, and which are missing
python3 tools/run_labs.py actually run the labs in a sandboxed HOME
python3 tools/test_harvest.py regression tests for the video-id matcher
python3 tools/verify_links.py HTTP-check every course URL, report dead links
python3 tools/fetch_transcripts.py <lecture-id> pull YouTube captions via yt-dlp
./run.sh validate → check labs → build → serve

Why check_shell_blocks.py exists

Several labs write a markdown file with a heredoc, and that generated
markdown contains its own code fences:

cat > 05-etm.md <<'EOF'
# Encrypt-then-MAC

ENCRYPT-THEN-MAC MAC-THEN-ENCRYPT


EOF
echo "written"

The bare ``` inside the body closes the outer block as far as
CommonMark is concerned, so the reader copies a script that stops
mid-heredoc. bash -n does not catch this — an unterminated
heredoc is only a warning — and running it hangs the terminal
indefinitely, with the block ending so plausibly that there is no
clue it was ever incomplete.

That was true of 40 notes. This tool found them by asking two
questions of every block: does it parse, and does it have an open
heredoc. It writes no files and runs no lab — several labs touch the
network, and AEGIS's scope discipline depends on them not firing by
accident.

How progression works

A tier unlocks when the tier below it is sufficiently mastered:

  • ≥70% of that tier's lectures marked cleared
  • ≥60% average self-test score

Locked tiers render redacted rather than hidden. Clearing all nine requires a documented capstone
engagement against your own lab range.

Every lecture tags concepts from a 405-node knowledge graph. Open any concept to see every lecture —
across every course and every tier — that touches it. That is how topics connect to each other.

Git

git log --oneline              # your study timeline, one commit per activity
git remote -v                  # cnpt9db5gp-cpu/AEGIS (private)

Progress auto-commits and pushes whenever you clear a lecture.

Safety

Read docs/RULES-OF-ENGAGEMENT.md before anything else. Every lab targets localhost or a lab range you
own. No exceptions.

Fonts

Barlow Condensed, IBM Plex Mono and Inter are vendored as latin-subset WOFF2 under
site/assets/fonts/ (SIL Open Font License), so the interface renders correctly offline.
Regenerate with python3 tools/fetch_fonts.py site/assets/fonts.
