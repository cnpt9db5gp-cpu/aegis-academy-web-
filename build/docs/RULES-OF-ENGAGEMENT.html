Rules of Engagement — AEGIS

Standing orders for everything in this repository. These are not suggestions.

1. The authorisation test

Before touching any system, you must be able to answer yes to all four:

  1. Do I own it, or have I been paid to test it?
  2. Is there a written scope — which IPs, domains, accounts, techniques, and time window?
  3. Have I written down what is out of bounds? (data destruction, DoS, social engineering, third parties)
  4. Would I be comfortable if the client's legal team read my exact commands?

If any answer is no, stop. Use a lab instead.

2. What counts as a legal target

Target Status
Your own Kali machine (localhost / loopback) Always fine
Virtual machines you created Always fine
Deliberately vulnerable images (Metasploitable, DVWA, Juice Shop, WebGoat) Always fine — the image exists to be attacked
OverTheWire, picoCTF, TryHackMe, Hack The Box, CyberDefenders Fine — the platform grants authorisation
PortSwigger Web Security Academy Fine — labs are explicitly provided for this
A CTF challenge you were invited to Fine — check the rules, usually no scanning outside the target IP
Anyone else's system Never, without a signed engagement letter

3. Hard limits

  • Never scan, probe or connect to anything you do not own or have authorisation for.
  • Never run denial-of-service tooling, even "just to test".
  • Never exfiltrate real personal data. If a lab exposes real credentials or PII, stop, note it, and do not spread it.
  • Never use findings to actually access systems beyond the agreed scope.
  • Never install or execute a tool from an unverified source during a study session — you would not do it on a client machine.

4. Data handling

Anything you capture while learning — pcaps, memory images, credential hashes — stays on your own machine
and inside this private repository. transcripts/ and lab artefacts are git-ignored by design.

5. Reporting

Finding a vulnerability in a system you are not authorised to test is not a "first blood". It is someone
else's problem, and the responsible move is to report it privately to the owner, not to publish it.

Knowledge without authorisation is liability. Knowledge with authorisation is a career.
