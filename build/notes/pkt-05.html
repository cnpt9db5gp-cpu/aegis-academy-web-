Automating Analysis with tshark and jq

Summary

The point of a capture is the answer, and the answer should be reproducible. tshark turns
packets into fields; jq turns fields into structure. Together they are how an analyst processes
more traffic than they can read.

Key ideas

  • tshark -T fields gives you tab-separated columns — machine-readable output
  • -Y takes a display filter; -e selects fields; -T json is even easier to post-process
  • jq filters, groups, and reshapes JSON without a language
  • Extract first, analyse second: never parse a pcap with ad-hoc text tools
  • Save the query, not just the answer, so the analysis is repeatable and reviewable
  • Same discipline as writing an exploit: the script is the artefact

Terminology

Term Meaning
Field extraction Pulling specific columns out of a dissector
-T fields / -T json Output formats of tshark
-Y Display filter (equivalent to Wireshark's filter box)
-e Which field to emit
jq JSON filter and transform language
jq filters .a.b, .[], select(...), group_by(...)
Aggregation Counting and grouping in one pipeline
Pipeline Output of one command feeding the next
Repeatable analysis A saved query, not a one-off command

Kali commands

command -v tshark jq

# --- field extraction, the core skill ---
tshark -r cap.pcap -T fields -e frame.number -e ip.src -e ip.dst -e tcp.srcport -e tcp.dstport
tshark -r cap.pcap -T fields -e ip.src 2>/dev/null | sort | uniq -c | sort -rn
tshark -r cap.pcap -Y "http.response" -T fields -e http.response.code 2>/dev/null | sort | uniq -c
tshark -r cap.pcap -Y "dns" -T fields -e dns.qry.name 2>/dev/null | sort -u | head -20

# --- JSON output, when structure matters ---
tshark -r cap.pcap -T json 2>/dev/null | head -c 400
tshark -r cap.pcap -T json 2>/dev/null | jq '.[] | {no: .["frame.number"], src: .["ip.src"]}'

# --- jq essentials ---
echo '{"a":1,"b":[{"c":2},{"c":3}]}' | jq '.'
echo '{"a":1,"b":[{"c":2},{"c":3}]}' | jq '.b[].c'
echo '{"a":1,"b":[{"c":2},{"c":3}]}' | jq '.b[] | select(.c > 2)'
echo '{"a":1,"b":[{"c":2},{"c":3}]}' | jq '[.b[].c] | add'
echo '{"a":1,"b":[{"c":2},{"c":3}]}' | jq -r '.b[] | "\(.c)"'

# --- the combination that does real work ---
tshark -r cap.pcap -Y "dns.flags.response == 1" -T json 2>/dev/null \
  | jq -r '.[]._source.layers.dns.qry.name' 2>/dev/null | sort -u | head -20

Field lab

Objective: build a reusable analysis script that answers three questions about a capture.

# --- PRE-FLIGHT: this lab needs root, so authenticate ONCE, HERE, first ---
# `sudo something &` backgrounds the password PROMPT along with the command.
# With no terminal attached to answer it, sudo fails - and `2>/dev/null`
# then throws away the only clue. The result is a capture file that was
# never written, followed by a screenful of "no such file".
#
# `sudo -v` validates the credential in the FOREGROUND, where you can see
# and answer the prompt. It caches for ~15 minutes, so every backgrounded
# `sudo` below is prompt-free and actually runs.
if ! sudo -v; then
  echo "  sudo is unavailable or the password was wrong - stop here." >&2
  echo "  Everything below needs root. Nothing will be captured." >&2
  exit 1
fi
mkdir -p ~/aegis/labs/pkt-05 && cd ~/aegis/labs/pkt-05

# --- 1. build a capture worth analysing ---
sudo tcpdump -i lo -n -w base.pcap -s 0 2>/dev/null &
TC=$!; sleep 1
( nc -l -p 8080 >/dev/null 2>&1 & )
( nc -l -p 9090 >/dev/null 2>&1 & )
sleep 1
for i in $(seq 1 5); do echo "GET / HTTP/1.0" | timeout 2 nc 127.0.0.1 8080 2>/dev/null; done
for i in $(seq 1 3); do echo "x $i" | timeout 2 nc 127.0.0.1 9090 2>/dev/null; done
for i in 1 2 3; do dig +short "name$i.example" @127.0.0.1 >/dev/null 2>&1; done
sleep 5; kill $TC 2>/dev/null; wait $TC 2>/dev/null
ls -la base.pcap

# --- 2. Q1: who talked to whom, ranked by volume ---
cat > who_talked.sh <<'EOF'
#!/usr/bin/env bash
# Q1: which host pairs exchanged the most packets?
set -euo pipefail
CAP="${1:-base.pcap}"
tshark -r "$CAP" -T fields -e ip.src -e ip.dst 2>/dev/null \
  | grep -v '^$' \
  | awk '{print $1" -> "$2}' \
  | sort | uniq -c | sort -rn | head -15
EOF
chmod +x who_talked.sh
echo "=== Q1: conversations by volume ==="
./who_talked.sh base.pcap | tee 01-who.txt

# --- 3. Q2: distinct ports contacted, per destination ---
cat > ports_per_host.sh <<'EOF'
#!/usr/bin/env bash
# Q2: how many distinct ports did each host contact? (scan heuristic)
set -euo pipefail
CAP="${1:-base.pcap}"
tshark -r "$CAP" -T fields -e ip.src -e tcp.dstport -e udp.dstport 2>/dev/null \
  | awk 'NF>1 { for(i=2;i<=NF;i++) if($i!="") print $1, $i }' \
  | sort -u | awk '{print $1}' | sort | uniq -c | sort -rn
EOF
chmod +x ports_per_host.sh
echo
echo "=== Q2: distinct destination ports per source ==="
./ports_per_host.sh base.pcap | tee 02-ports-per-host.txt
echo
echo "  A source contacting dozens of ports on one host = scanning."
echo "  This single query detects most port scans."

# --- 4. Q3: DNS names, deduplicated, via jq ---
cat > dns_names.sh <<'EOF'
#!/usr/bin/env bash
# Q3: every DNS name in the capture, deduplicated.
set -euo pipefail
CAP="${1:-base.pcap}"
if tshark -r "$CAP" -Y "dns.qry.name" -T json 2>/dev/null | jq -e '.' >/dev/null 2>&1; then
  tshark -r "$CAP" -Y "dns.qry.name" -T json 2>/dev/null \
    | jq -r '.[]._source.layers.dns.qry.name' 2>/dev/null
else
  tshark -r "$CAP" -Y "dns.qry.name" -T fields -e dns.qry.name 2>/dev/null
fi
EOF
chmod +x dns_names.sh
echo
echo "=== Q3: DNS names seen ==="
./dns_names.sh base.pcap | sort -u | tee 03-dns.txt
echo
echo "  A jQuery filter is more robust than a text field extraction - it fails"
echo "  loudly rather than silently producing columns in the wrong order."

# --- 5. the jq cheat sheet ---
cat > 04-jq.md <<'EOF'
# jq, for people who analyse captures

    .                 the whole input
    .a.b              nested field
    .[]               iterate an array
    .[] | select(...) filter elements
    .[] | {x: .x}    reshape
    map(...)          apply to every element
    add               sum an array of numbers
    length            count
    group_by(.x)      group an array by a key
    sort_by(.x)       sort an array
    unique            deduplicate
    keys              object keys
    to_entries        object -> array of {key, value}

## Practical patterns for packet analysis

    # top talkers
    ... | jq -r '.[]._source.layers.ip.src' | sort | uniq -c | sort -rn

    # only successful responses
    ... | jq -r '.[] | select(._source.layers.http.response.code >= 200)'

    # pairs as one string
    ... | jq -r '.[] | "\(._source.layers.ip.src) -> \(._source.layers.ip.dst)"'

    # tally in jq itself
    ... | jq -r '.[]._source.layers.tcp.dstport' | sort | uniq -c | sort -rn
EOF
cat 04-jq.md

# --- 6. a full report in one command ---
cat > 05-report.sh <<'EOF'
#!/usr/bin/env bash
# Full automated triage of a capture. One script, repeatable.
set -euo pipefail
CAP="${1:-base.pcap}"
BAR=$(printf '=%.0s' {1..66})

echo "$bar"
echo "CAPTURE TRIAGE: $CAP"
capinfos "$CAP" 2>/dev/null | grep -E "File size|Number of packets|Time|Capture duration" | sed 's/^/  /'
echo

echo "$bar"; echo "1. PROTOCOL MIX"
tshark -r "$CAP" -q -z io,phs 2>/dev/null | head -14 | sed 's/^/  /'
echo

echo "$bar"; echo "2. TOP TALKERS (source addresses)"
tshark -r "$CAP" -T fields -e ip.src 2>/dev/null | grep -v '^$' | sort | uniq -c | sort -rn | head -8 | sed 's/^/  /'
echo

echo "$bar"; echo "3. TOP DESTINATION PORTS"
tshark -r "$CAP" -T fields -e tcp.dstport -e udp.dstport 2>/dev/null \
  | tr '\t' '\n' | grep -v '^$' | sort -n | uniq -c | sort -rn | head -10 | sed 's/^/  /'
echo

echo "$bar"; echo "4. SCAN INDICATOR: distinct ports per source"
./ports_per_host.sh "$CAP" | awk '$1 > 10 {print "  *** " $1 " ports from " $2 " -- possible scan"}' | head -10
echo "  (nothing above threshold = no obvious scanning)"
echo

echo "$bar"; echo "5. DNS NAMES"
./dns_names.sh "$CAP" | sort -u | head -15 | sed 's/^/  /'
echo

echo "$bar"; echo "6. HTTP RESPONSES"
tshark -r "$CAP" -Y "http.response.code" -T fields -e http.response.code 2>/dev/null \
  | sort | uniq -c | sort -rn | head -8 | sed 's/^/  /'
echo
echo "$bar"
EOF
chmod +x 05-report.sh
./05-report.sh base.pcap | tee 06-report.txt
echo
echo "=== One command, six answers. This is the skill. ==="

Step 6 is the deliverable: a single repeatable triage script that answers six questions
about any capture you point it at.
