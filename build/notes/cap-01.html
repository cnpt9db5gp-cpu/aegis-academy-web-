Engagement Planning and Authorisation

Summary

The capstone is not a technique. It is a run: five stages, one authorisation document, one diary,
one report. This note is stage zero — the plan, the authorisation, and the decision to stop.

The framing: the capstone's deliverable is not the domain admin
shell. It is a report that another engineer can act on and a diary
that shows you stayed inside the line the whole time.

This note opens Tier 8. cap-02..cap-06 are the run, in order.
Everything in tiers 1–7 is the toolkit this draws on.

The shape of the capstone

  cap-01  plan and authorise      <- this note
  cap-02  reconnaissance          OSINT -> passive -> active -> map
  cap-03  initial access          exploit the exposure you found
  cap-04  privilege and lateral   escalate, pivot, reach the objective
  cap-05  evidence and detection  timeline, artefacts, and what the
                                  client's monitoring would or would
                                  not have seen
  cap-06  report and retrospective the deliverable, and what you
                                  learned about the process

  THE OBJECTIVE, stated so it is checkable:
    "Obtain Domain Administrator in lab.internal and demonstrate
     database read access, using only the techniques and tooling in
     tiers 1-7, without leaving artefacts."

  NOTE "without leaving artefacts". That clause is the real exercise.
  Getting the shell is the easy half. Getting it, documenting it,
  and cleaning it up is the half that is actually assessed.

# AUTHORISATION — AEGIS CAPSTONE

## Parties
- System under test:  the aegis.lab forest and its hosts, in a
                      VirtualBox host-only lab on this machine
- Owner:               I built this lab, from ISO images, on hardware
                       I own. It contains no real data.
- Authorising party:   me, as the operator of the host
- Basis:               this lab exists for security education and
                       the systems in it are deliberately vulnerable

## Scope: IN
| Target | Range | Role in the exercise |
|---|---|---|
| 192.168.56.0/24 | host-only | "external" - where you sit |
| 10.10.10.0/24 | host-only | "internal" - only via a pivot |
| DC01 .56.10 + 10.10.10.5 | both | domain controller, the pivot path |
| DC02 .56.11 + 10.10.10.6 | both | second DC, replication |
| WKS01 .56.20 | external | unprivileged workstation |
| WKS02 .56.21 | external | privileged workstation |
| SRV01 10.10.10.20 | internal | app + file server, internal only |
| 127.0.0.1 | loopback | DVWA |

## Scope: OUT
| Target | Reason |
|---|---|
| Every public IP | there is no authorised public target in this project |
| Every address outside the two lab ranges | default deny |
| 10.0.0.0/8 and 172.16.0.0/12 | not mine |
| Any real domain, any real organisation | not mine |
| Denial of service | prohibited |
| Social engineering | prohibited |
| The host's real LAN (192.168.1.0/24) | NOT in scope. See below. |

## The 192.168.1.0/24 entry, which is the important one
My workstation's real LAN address is 192.168.1.120. It is NOT in
scope, because scope is what I wrote down, not what I own. Every
script in this project is gated by scope-guard.sh, which refuses
anything outside 192.168.56.0/24 and 10.10.10.0/24. That guard
exists so that "it is technically mine" never becomes "therefore it
is in scope".

## Prohibited, unconditionally
- denial of service of any kind, including on the lab
- any traffic to a non-loopback address outside the two lab ranges
- social engineering of any kind
- modifying or destroying data outside the lab

## Permitted
- network scanning and service enumeration of in-scope ranges
- exploitation of the deliberate misconfigurations in the lab
- credential extraction from the lab (there is nothing real in it)
- lateral movement and pivoting within the lab

## Stop conditions (written before starting, honoured immediately)
1. Any traffic would leave 192.168.56.0/24 or 10.10.10.0/24 -> STOP
2. Any lab service becomes unavailable and I cannot explain it -> STOP
3. I am unsure whether something is in scope -> STOP
4. The exercise stops producing findings and starts producing risk -> STOP

## Evidence handling
- all evidence under ~/aegis/labs/cap-01/evidence/, mode 0700
- nothing leaves this machine except the report
- the report will contain no live credential
EOF

cat > 01-PLAN.md <<'EOF'
# Capstone plan

## The objective
Obtain Domain Administrator in aegis.lab and demonstrate database
read access on SRV01, without leaving artefacts.

## The hypotheses, written in advance
These are the *expected* findings. Write them before you start, or
you will find something, believe it, and never test the alternative.

  H1  Anonymous LDAP is open, so the whole domain can be enumerated
      with no credentials. (ad-03)
  H2  At least one account has preauth disabled, so AS-REP roasting
      works with no credentials at all. (ad-04)
  H3  Service accounts have SPNs and RC4, so Kerberoasting recovers a
      password. (ad-04)
  H4  The recovered password is for an account in a privileged group.
      (ad-01)
  H5  SMB signing is not required, so relay is possible. (imp-03)
  H6  One host has unconstrained delegation, so a TGT can be captured
      without any credential. (ad-02)
  H7  helpdesk has GenericAll on a group, giving a long path to
      privilege. (bh-02)

  THE POINT OF WRITING THEM DOWN: after the run you compare what you
  found against what you expected. The gaps are as informative as the
  hits, and they are what the retrospective is made of.

## The stages and their stop conditions

  1. RECON (cap-02)     stop if: a script would touch a non-lab address
  2. ACCESS (cap-03)    stop if: no path exists without exploitation
                        of something out of scope
  3. ESCALATE (cap-04)  stop if: escalation would leave an artefact
                        I cannot verify removal of
  4. DOCUMENT (cap-05)  stop if: collecting evidence would modify state
  5. REPORT (cap-06)    stop if: a claim in the report cannot be
                        evidenced

## The artefacts each stage must produce

  1. recon      an asset map, and the OSINT coverage checklist
  2. access     the exact request, and the minimal proof
  3. escalate   a session log: what, where, as whom, how
  4. document   a timeline, hashes for every artefact, and a
                statement of what the client's monitoring would have
                or would not have seen
  5. report     a report a stranger can act on, and a retrospective

## Time budget and where it goes
  recon      30%     (this is where the real thinking is)
  access     15%
  escalate   25%
  document   20%     (always under-budgeted; always needs more)
  report     10%
EOF

cat > 02-scope-guard.py <<'PY'
#!/usr/bin/env python3
"""The scope guard, as a library.

Every networked action in the capstone imports this. It is the
enforcement point for the authorisation in 00-AUTHORISATION.md.
"""
import ipaddress, sys, socket

# The two lab ranges. Nothing else is in scope, including the host's
# own real LAN address, which is a documented design decision.
IN_SCOPE_NETWORKS = [
    ipaddress.ip_network("192.168.56.0/24"),
    ipaddress.ip_network("10.10.10.0/24"),
]
LOOPBACK = [ipaddress.ip_network("127.0.0.0/8"),
            ipaddress.ip_network("::1/128")]

class OutOfScope(Exception):
    pass

def resolve(host: str) -> list[str]:
    try:
        return sorted({ai[4][0] for ai in
                       socket.getaddrinfo(host, None, proto=socket.IPPROTO_TCP)})
    except Exception:
        return []

def in_scope(host: str) -> tuple[bool, str]:
    """Return (ok, reason). Never returns (True, '') on a guess."""
    try:
        addrs = [ipaddress.ip_address(host)]
    except ValueError:
        addrs = [ipaddress.ip_address(a) for a in resolve(host)] if host else []
    if not addrs:
        return False, f"cannot resolve {host!r} - refusing to guess"
    for a in addrs:
        if any(a in n for n in LOOPBACK): continue
        if not any(a in n for n in IN_SCOPE_NETWORKS):
            return False, (f"{a} is not in the authorised lab ranges "
                           f"(192.168.56.0/24, 10.10.10.0/24)")
    return True, f"{host} -> {', '.join(str(a) for a in addrs)} (all in scope)"

def check(*hosts) -> None:
    """Raise on any out-of-scope host. Use this before every action."""
    for h in hosts:
        ok, why = in_scope(h)
        if not ok:
            print(f"REFUSED: {why}", file=sys.stderr)
            print("  This project has no authorised public target.", file=sys.stderr)
            print("  Scope is what the authorisation says, not what is", file=sys.stderr)
            print("  technically reachable.", file=sys.stderr)
            raise OutOfScope(why)
        print(f"[scope] {why}")

def guard(*hosts):
    """Decorator form, for anything that takes a target."""
    def deco(fn):
        def wrapped(*a, **kw):
            targets = []
            for arg in a:
                if isinstance(arg, str) and _looks_like_host(arg):
                    targets.append(arg)
            check(*targets)
            return fn(*a, **kw)
        return wrapped
    return deco

def _looks_like_host(s: str) -> bool:
    import re
    return bool(re.match(r"^\d{1,3}(\.\d{1,3}){3}$", s) or
                re.match(r"^[a-z0-9-]+\.[a-z0-9.-]+$", s, re.I))

if __name__ == "__main__":
    # the self-test, and it should always be run before the engagement
    print("  SCOPE GUARD SELF-TEST")
    cases = [
        ("192.168.56.10", True),  ("192.168.56.254", True),
        ("10.10.10.20",   True),  ("127.0.0.1",       True),
        ("192.168.1.120", False), # the host's REAL lan address
        ("8.8.8.8",       False), ("1.1.1.1",        False),
        ("172.20.0.1",    False), # RFC1918, but not a LAB range
        ("10.255.255.255",False),
        ("nonexistent.invalid", False),
    ]
    bad = 0
    for host, expected in cases:
        got, why = in_scope(host)
        ok = "ok  " if got == expected else "FAIL"
        if got != expected: bad += 1
        print(f"  [{ok}] {host:<22} {'IN ' if got else 'OUT'}  {why[:44]}")
    print(f"\n  {len(cases)-bad}/{len(cases)} decisions correct.")
    if bad:
        print("  THE GUARD IS BROKEN. Do not run the engagement.")
    sys.exit(1 if bad else 0)
PY
