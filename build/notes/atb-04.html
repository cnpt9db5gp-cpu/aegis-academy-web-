Networking Scripts and Sockets

Summary

Python as a network client and server. This is the lecture where the tools stop being commands
you type and become programs you own — and where you see exactly what a "connection" is.

Key ideas

  • socket, create_connection, bind/listen/accept/connect
  • TCP vs UDP semantics, and why UDP scanning is unreliable
  • Timeouts are mandatory — a blocking read with no timeout hangs forever
  • recv returns up to N bytes; loop until you have what you need
  • A one-shot HTTP request written by hand, to see the wire format
  • sendall vs send — send may write partially
  • selectors or threads for a multi-connection server

Terminology

Term Meaning
Socket Kernel object for a network endpoint
IP:port What identifies a socket
bind/listen/accept Server side
connect Client side
SOCK_STREAM / SOCK_DGRAM TCP / UDP
Blocking / non-blocking Whether a call waits
Timeout Mandatory deadline on a socket operation
recv Read up to N bytes
sendall Write all bytes or fail
Little/big-endian Byte order; matters for binary protocols
Selector loop One thread handling many sockets

# --- what greets you on loopback, in 15 lines ---
python3 - <<'PY'
import socket
for port in (21,22,23,25,80,110,143,443,3306,5432,8080):
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=0.4) as s:
            s.settimeout(0.4)
            try:    b = s.recv(96).decode("utf8","replace").strip()[:44]
            except socket.timeout: b = "(open, no banner)"
            print(f"  {port:<6} open   {b}")
    except ConnectionRefusedError: pass
    except socket.timeout:        print(f"  {port:<6} filtered")
    except OSError as e:          print(f"  {port:<6} {type(e).__name__}")
PY

# --- a hand-written HTTP GET ---
python3 - <<'PY'
import socket
req = b"GET / HTTP/1.1\r\nHost: 127.0.0.1\r\nUser-Agent: aegis\r\nConnection: close\r\n\r\n"
print("  request bytes:")
for i in range(0, len(req), 16):
    chunk = req[i:i+16]
    print("   ", chunk.hex(" "), " |", "".join(chr(b) if 32 <= b < 127 else "." for b in chunk))
try:
    with socket.create_connection(("127.0.0.1", 80), timeout=2) as s:
        s.sendall(req); data = b""
        while chunk := s.recv(4096): data += chunk
    print("  response:", data[:200].decode("utf8","replace"))
except OSError as e:
    print("  no http on 80:", type(e).__name__)
PY

Field lab

Objective: write a scanner with a listener, so you see both sides of a connection.

mkdir -p ~/aegis/labs/atb-04 && cd ~/aegis/labs/atb-04

cat > netserv.py <<'PY'
#!/usr/bin/env python3
# netserv.py - a tiny multi-connection TCP server, then a client that talks to it.
import socket, threading, sys, time

BANNER = b"AEGIS-LAB-1.0\r\n"

def handle(conn, addr):
    with conn:
        conn.settimeout(3)
        conn.sendall(BANNER)
        try:
            data = conn.recv(1024)
        except socket.timeout:
            data = b""
        print(f"  [server] {addr} said: {data[:60]!r}")
        conn.sendall(b"HELLO FROM SERVER\n")

def serve(host="127.0.0.1", port=9001, n=2):
    srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind((host, port))
    srv.listen(5)
    print(f"  [server] listening on {host}:{port}")
    for _ in range(n):
        conn, addr = srv.accept()
        threading.Thread(target=handle, args=(conn, addr), daemon=True).start()
    srv.close()

def client(host="127.0.0.1", port=9001, message=b"ping\n"):
    with socket.create_connection((host, port), timeout=3) as s:
        s.settimeout(3)
        banner = s.recv(128)
        print(f"  [client] banner: {banner!r}")
        s.sendall(message)
        print(f"  [client] sent  : {message!r}")
        print(f"  [client] reply : {s.recv(128)!r}")

if __name__ == "__main__":
    role = sys.argv[1] if len(sys.argv) > 1 else "both"
    if role in ("serve", "both"):
        threading.Thread(target=serve, daemon=True).start()
        time.sleep(0.4)
    if role in ("client", "both"):
        client()
        client(b"second connection\n")
PY
chmod +x netserv.py

echo "=== run both sides in one process ==="
python3 netserv.py both | tee 01-loop.txt

echo
echo "=== split across two terminals instead ==="
echo "  terminal 1:  python3 netserv.py serve"

echo
echo "=== netcat, same conversation, no Python ==="
python3 netserv.py serve >/dev/null 2>&1 &
SRVPID=$!; sleep 0.5
printf 'ping\n' | timeout 3 nc -v 127.0.0.1 9001 | head -3
kill $SRVPID 2>/dev/null

echo
echo "=== why timeouts matter: prove the hang ==="
python3 - <<'PY'
import socket, time
t = time.time()
try:
    socket.create_connection(("192.0.2.1", 9), timeout=2)   # TEST-NET-1
except OSError as e:
    print(f"  with timeout   : gave up after {time.time()-t:.1f}s ({type(e).__name__})")
print("  without timeout: would block indefinitely")
print("  (uncomment socket.create_connection(('192.0.2.1', 9)) in a terminal to feel it)")
PY

Step 1 vs step 4 is the lesson: your program and netcat produce the same bytes on the wire. A
protocol is a protocol regardless of what implements it — and once you can see the bytes, you can
craft them by hand.
