Branching, Conditionals, Iteration

Summary

MIT 6.0001's opening block is the foundation of all programming. This lecture covers assignment,
conditionals and loops — and, more importantly for security, the type system, because the
difference between the string "5" and the integer 5 is the root of a large fraction of
real-world web vulnerabilities.

You do not need object-oriented programming yet. You need to write a function that takes input,
makes decisions, loops over data, and returns a result.

Values and types

type(5)        # <class 'int'>
type(5.0)      # <class 'float'>
type("5")      # <class 'str'>   <- the quotes are the difference
type(True)     # <class 'bool'>
type([1,2,3])  # <class 'list'>
type({"a":1})  # <class 'dict'>

In Python, "5" + 5 raises TypeError. In C, the equivalent conversion happens silently.
Confusion between input-as-string and input-as-number is behind a large share of authentication
bypass and injection bugs, and it is exactly why ssh://host:022 and ssh://host:22 can behave
differently to different parsers.

Conditionals

if x > 10:
    print("big")
elif x > 5:
    print("medium")
else:
    print("small")

label = "big" if x > 10 else "small"      # ternary

Truthiness — what Python considers false

bool(0)      # False
bool(0.0)    # False
bool("")     # False   <- empty string
bool("0")    # True    <- non-empty string! a classic bug source
bool([])     # False
bool([0])    # True    <- a list containing zero is truthy
bool(None)   # False

bool("0") being True is the one that bites. If you write if not password: in a language with
C-style truthiness, the string "0" would let someone in.

Loops

for i in range(5):            # 0 1 2 3 4  <- stop is EXCLUSIVE
for i in range(2, 10, 2):     # 2 4 6 8
for name in ["alice", "bob"]: ...
for i, name in enumerate([...]): ...

count = 0
while count < 5:
    count += 1

range(5) stops before 5. This single fact causes more off-by-one bugs than anything else in
introductory programming.

break / continue / else

for n in [3, 7, 11]:
    if n % 2 == 0:
        continue          # skip
    if n > 10:
        break             # stop
else:
    print("ran to completion without break")

The for...else is Python-specific and genuinely useful: it is the idiomatic way to express
"the loop searched and found nothing" — exactly what a scanner needs to report.

Reading and parsing — the actual security use

# /etc/passwd -> name:uid:gid:gecos:home:shell
with open("/etc/passwd") as f:
    for line in f:
        if line.startswith("#"):
            continue
        fields = line.strip().split(":")
        if len(fields) < 7:
            continue
        name, uid, _, _, home, shell = fields[:6]
        if uid == "0":
            print(f"root-equivalent: {name} -> {shell}")

That is genuine enumeration in twelve lines, and it is exactly what you would run against a
target you are authorised to test.

Terminology

Term Meaning
Type The category of a value; determines legal operations
Truthiness What Python coerces to True/False
Range exclusivity range(5) is 0-4
break / continue Exit the loop / skip an iteration
for...else else runs only if no break occurred
Indentation Python's block structure; 4 spaces, mandatory
Exception Python's runtime error mechanism
with Context manager guaranteeing cleanup
f-string f"{x}" — formatted string literal
Traceback The error report; read it bottom-up

import re, sys

LINE = re.compile(r"^(?P<port>\d+)/(?P<proto>tcp|udp)\s+open\s+(?P<service>\S+)(?:\s+(?P<version>.+))?$")

def parse(path):
    out = []
    for line in open(path, errors="replace"):
        m = LINE.match(line.rstrip())
        if m:
            d = m.groupdict()
            d["port"] = int(d["port"])
            d["version"] = (d["version"] or "").strip()
            out.append(d)
    return out

INTEREST = {"http","https","ftp","ssh","telnet","smb","mysql","postgresql",
            "redis","mongodb","rpcbind","smtp","ldap"}

if __name__ == "__main__":
    rows = parse(sys.argv[1] if len(sys.argv) > 1 else "loopback-scan.txt")
    print(f"{len(rows)} open ports\n")
    print(f"{'PORT':<7}{'PROTO':<7}{'SERVICE':<14}{'FLAG':<7}VERSION")
    print("-" * 70)
    for r in sorted(rows, key=lambda r: (r["service"] not in INTEREST, -r["port"])):
        flag = "<<<" if r["service"] in INTEREST else ""
        print(f"{r['port']:<7}{r['proto']:<7}{r['service']:<14}{flag:<7}{r['version']}")
PY

# --- for...else in its real use ---

def find_root_ssh(log):
    for line in log:
        if "Accepted password for root" in line:
            return line.strip()
    else:
        return "no root SSH logins found"
print(find_root_ssh(["Accepted password for nwpcs from 127.0.0.1"]))
print(find_root_ssh(["nothing here"]))
