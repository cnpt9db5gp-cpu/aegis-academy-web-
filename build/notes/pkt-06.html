DNS Exfiltration and Tunneling Detection

Summary

Traffic rarely leaves through the place you are watching. DNS is a strong candidate: it is
required before almost anything else works, it is usually permitted, and it is rarely inspected.
This lecture is about building a detector.

Key ideas

  • DNS exfiltration encodes data into subdomain labels and lets the resolver deliver it
  • 4f6752ba2321b7a3.hexpayload.attacker.com — each query carries a few bytes
  • Detection signals: subdomain entropy, query volume, query length, unusual TLDs,
    responses that are always NXDOMAIN (a tunnel, not real resolution)
  • DNS tunnelling (iodine, dns2tcp) carries a whole channel inside DNS
  • C2 over DNS: the malware queries a domain and reads instructions from TXT or A records
  • Defences: log everything, alert on entropy, restrict egress to your resolver only

Terminology

Term Meaning
DNS exfiltration Data smuggled out inside DNS queries
Subdomain label The part before the registrable domain
Entropy Randomness; high in encoded data, low in real names
NXDOMAIN The domain does not exist — expected in a tunnel
DNS tunnel A full channel inside DNS
iodine / dns2tcp DNS tunnelling tools
C2 over DNS Command and control using DNS
TXT record Free-text record, used to carry C2 data
Egress filtering Outbound network policy
Resolver log The single most valuable DNS evidence source

# --- 1. the encoder, written out so it is auditable ---
cat > encode.py <<'PY'
#!/usr/bin/env python3
"""
dns_exfil_encode.py - encode a file into DNS subdomains.
LAB ONLY. You must own the parent domain to receive the data, and you must
have written authorisation to test anything beyond your own machine.
"""
import base64, sys

def encode(path, chunk=30):
    raw = open(path, "rb").read()
    b64 = base64.b64encode(raw).decode().rstrip("=")
    return [b64[i:i+chunk] for i in range(0, len(b64), chunk)]

def entropy(s):
    import collections, math
    if not s: return 0.0
    c = collections.Counter(s)
    n = len(s)
    return -sum((v/n) * math.log2(v/n) for v in c.values())

if __name__ == "__main__":
    path = sys.argv[1] if len(sys.argv) > 1 else "message.txt"
    domain = sys.argv[2] if len(sys.argv) > 2 else "tunnel.example.com"
    labels = encode(path)
    print(f"  {path} -> {len(labels)} queries")
    print(f"  first: {labels[0]}.{domain}")
    print(f"  mean label entropy: {sum(entropy(l) for l in labels)/len(labels):.2f} bits/char")
    with open("queries.txt", "w") as f:
        for l in labels:
            f.write(f"{l}.{domain}\n")
PY

# --- 3. the detector ---
cat > detect.py <<'PY'
#!/usr/bin/env python3
"""
detect.py - score DNS queries for exfiltration indicators.
Input: one query name per line. Output: score + reason.
"""
import sys, math, collections

COMMON_TLDS = {"com","net","org","co","io","gov","edu","uk","de","fr","info"}
def entropy(s):
    if not s: return 0.0
    c = collections.Counter(s)
    n = len(s)
    return -sum((v/n) * math.log2(v/n) for v in c.values())

def score(name):
    labels = name.strip().rstrip(".").split(".")
    if len(labels) < 2: return 0, "too short"
    reasons, pts = [], 0
    sub = labels[0]
    e = entropy(sub)
    if len(sub) >= 20: pts += 2; reasons.append(f"long label ({len(sub)} chars)")
    if e >= 3.5:      pts += 3; reasons.append(f"high entropy ({e:.2f})")
    if re_like(sub):  pts += 2; reasons.append("base64/hex character set")
    tld = labels[-1]
    if tld not in COMMON_TLDS: pts += 2; reasons.append(f"uncommon TLD .{tld}")
    if len(labels) > 4:     pts += 1; reasons.append("deep subdomain")
    return pts, "; ".join(reasons) or "looks normal"

def re_like(s):
    import re
    return bool(re.fullmatch(r"[A-Za-z0-9+/=_-]{16,}", s))

if __name__ == "__main__":
    lines = [l for l in open(sys.argv[1]) if l.strip()]
    scored = [(score(l), l.strip()) for l in lines]
    scored.sort(key=lambda x: -x[0][0])
    for (pts, why), name in scored[:15]:
        flag = "*** EXFIL-SUSPICIOUS" if pts >= 4 else "ok"
        print(f"  {pts:>2}  {flag:<18} {name[:52]}  [{why}]")
    hits = sum(1 for (p,_),_ in scored if p >= 4)
    print(f"\n  {hits}/{len(scored)} queries scored above the exfil threshold")
PY

# --- 5. the defence, in the order you would deploy it ---
cat > 04-defence.md <<'EOF'
# Detecting and preventing DNS tunnelling

## 1. Log everything (do this first)
    logging { query; response; };
or equivalent in resolved/your resolver. Without logs you have no detection
and no evidence. This is the single highest-value control in this lecture.

## 2. Alert on the signals
- subdomain label entropy above ~3.5 bits/char
- label length above 30 characters
- base64 or hex character sets in labels
- query volume per registered domain far above its baseline
- high proportion of NXDOMAIN responses
- any TXT response that is not a known SPF/DKIM record

## 3. Constrain egress
Force all hosts to use your internal resolvers, and block direct outbound
port 53 from endpoints. A client that cannot choose its own resolver cannot
exfiltrate through one.

## 4. Constrain the payload
Filter at the resolver: reject labels matching `[A-Za-z0-9+/=]{30,}`.
Crude, but effective, and it is a legitimate production control.

## 5. Egress firewall as the backstop
Only the resolvers and proxies may reach the internet. Everything else speaks
to them.

## What you are actually defending against
Data leaving through a channel that was never designed to carry it, by an
application that never touches the network directly. The same reasoning
applies to DNS-over-HTTPS: it is legitimate, and it removes your visibility,
so it deserves an explicit policy decision rather than an accident.
EOF
cat 04-defence.md
