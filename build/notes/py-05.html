Exceptions, and Why Error Messages Are Documentation

Summary

Errors are not failures — they are the program telling you precisely what it cannot do, in
detail, for free. Beginners learn to avoid exceptions; operators learn to read them.

In security this matters more than most fields: an unhandled exception on a remote service is an
information disclosure vulnerability, and in CTF challenges a traceback is frequently the clue.

The hierarchy that matters

BaseException
├── KeyboardInterrupt        (Ctrl+C - handle it, never swallow it)
├── SystemExit
└── Exception
    ├── SyntaxError / IndentationError
    ├── ValueError         right type, wrong value
    ├── TypeError          wrong type entirely
    ├── KeyError / IndexError / AttributeError / NameError
    ├── OSError
    │   ├── FileNotFoundError
    │   ├── PermissionError
    │   └── ConnectionRefusedError
    └── socket.timeout / TimeoutError

The distinction to internalise: TypeError = wrong kind of thing, ValueError = right kind,
impossible value. They point at different bugs.

Reading a traceback

Traceback (most recent call last):
  File "scanner.py", line 42, in scan_host
    banner = sock.recv(256).decode("utf-8")
  File "/usr/lib/python3.13/socket.py", line 709, in recv_into
    data = self._sock.recv_into(b)
ConnectionResetError: [Errno 104] Connection reset by peer

Read bottom-up:

  1. Last line — exception type and message
  2. Line above — where it was raised (often the standard library)
  3. Line above that — your code, the exact line that triggered it
  4. Frames above that are the call path

The bug is almost always in your file.

Handling exceptions properly

# TOO BROAD - hides bugs and swallows Ctrl+C
try:    do_everything()
except: pass

# CORRECT - catch what you expect, and react
try:
    conn = socket.create_connection((host, port), timeout=2)
except (ConnectionRefusedError, socket.timeout, OSError):
    return None      # expected: closed or filtered

Never use bare except: — it catches KeyboardInterrupt and SystemExit, so Ctrl+C stops
working and your program becomes unkillable from the terminal.

try / except / else / finally

conn = None
try:
    conn = socket.create_connection(target, timeout=3)
    banner = conn.recv(256)
except ConnectionRefusedError:
    print("port closed")
except socket.timeout:
    print("filtered - no response")
except Exception as e:
    print(f"unexpected: {type(e).__name__}: {e}")   # log, keep going
else:
    print(f"got banner: {banner!r}")     # only on success
finally:
    if conn:
        conn.close()                     # ALWAYS runs

else runs only if no exception occurred. finally always runs. Cleanup belongs in
finally.

Raising your own errors

class ScopeError(Exception):
    """Raised when a target is outside the authorised scope."""

def scan(host, port):
    if not is_lab_address(host):
        raise ScopeError(f"{host} is outside RFC1918/loopback scope")

This is how you build a safety guard that cannot be bypassed by accident — and why the scope
guard in py-02 works.

Exit codes

import sys

def main():
    if len(sys.argv) < 2:
        print("usage: scanner.py <target>", file=sys.stderr); return 2
    try:
        results = scan(sys.argv[1])
    except ScopeError as e:
        print(e, file=sys.stderr); return 3     # refused, deliberately
    except ConnectionError:
        return 1
    print(len(results), "findings")
    return 0

sys.exit(main())

Then scripts can branch: scan.py host && notify.

Error messages as attack surface

Leaky (never ship) Safe
SQLException: syntax error near "admin" at line 1 400 Bad Request
FileNotFoundError: /var/www/app/.env 404 Not Found
psycopg2.OperationalError: user 'app' failed 503 Service Unavailable
NullPointerException at User.java:88 generic 500

Consistency matters too: if "no such user" and "wrong password" return different messages, you
have built a username enumerator. That is authentication-bypass in Tier 4.

Terminology

Term Meaning
Exception A raised error object
Traceback Call-stack report on an unhandled exception
try/except/else/finally Handle, distinguish success, always clean up
Bare except: Catches everything including Ctrl+C — always wrong
Re-raise raise inside except to propagate unchanged
Exit code Integer returned to the shell; 0 = success
Error oracle Behaviour differences that leak secret state
Information disclosure Leaking internals through error output

Field lab

Objective: build a scanner whose error handling is deliberate and whose scope guard cannot be
bypassed.

mkdir -p ~/aegis/labs/py-05 && cd ~/aegis/labs/py-05

cat > robust.py <<'PY'
import socket, sys, json, time

class ScopeError(Exception):
    pass

def is_lab_address(host):
    try:
        p = socket.inet_aton(host)
        return (p[0] == 127 or p[0] == 10 or
                (p[0] == 172 and 16 <= p[1] <= 31) or
                (p[0] == 192 and p[1] == 168))
    except OSError:
        return False

def connect(host, port, timeout=2.0):
    # status: open | refused | filtered | error
    try:
        sock = socket.create_connection((host, port), timeout=timeout)
    except ConnectionRefusedError:
        return "refused", ""
    except socket.timeout:
        return "filtered", ""
    except socket.gaierror as e:
        raise ScopeError(f"cannot resolve {host}: {e}") from e
    except OSError as e:
        return "error", f"{type(e).__name__}: {e}"
    try:
        sock.settimeout(1.5)
        try:
            return "open", sock.recv(256).decode("utf8","replace").strip()
        except socket.timeout:
            return "open", ""
        except ConnectionResetError:
            return "open", "<connection reset by peer>"
        except OSError as e:
            return "open", f"<{type(e).__name__}>"
    finally:
        sock.close()

def scan(host, ports):
    if not is_lab_address(host):
        raise ScopeError(f"REFUSING {host}: only loopback and RFC1918 are in scope. "
                         f"See docs/RULES-OF-ENGAGEMENT.md")
    started = time.time()
    results = []
    for port in ports:
        status, banner = connect(host, port)
        results.append({"port": port, "status": status, "banner": banner[:60]})
    return {"target": host, "elapsed_s": round(time.time()-started, 2),
            "results": results}

def main(argv):
    if len(argv) < 2:
        print(f"usage: {argv[0]} <host> [port ...]", file=sys.stderr); return 2
    host, ports = argv[1], [int(a) for a in argv[2:]] or [22,80,443,8080,3306]
    try:
        report = scan(host, ports)
    except ScopeError as e:
        print(f"\n  {e}\n", file=sys.stderr); return 3
    except KeyboardInterrupt:
        print("\ninterrupted", file=sys.stderr); return 130
    except Exception as e:
        print(f"unexpected failure: {type(e).__name__}: {e}", file=sys.stderr); return 1
    print(json.dumps(report, indent=2))
    return 0

if __name__ == "__main__":
    sys.exit(main(sys.argv))

def login(user, db):
    if user is None:  return False, "400 Bad Request"
    if user != "admin": return False, "401 Unauthorized"
    return False, "500 Internal Server Error"
