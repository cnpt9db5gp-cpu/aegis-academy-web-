Data Link Layer: Framing, MAC, Error Control

Summary

How bits become frames, how frames find their destination, and how errors are detected. Layer 2
is where the first security boundary of any network appears — and where the first attack surface
does too.

Key ideas

  • Framing: delimiters, addresses, type/length, payload, FCS
  • MAC addressing is flat: every node listens to every frame. No hierarchy, no broadcast
    control. That single property enables ARP poisoning and MAC flooding
  • Error control: CRC/FCS detects corruption but does not correct; the frame is simply dropped
  • Flow control: not really present in shared Ethernet; collision handling came with CSMA/CD
  • Switching replaced the collision domain problem but kept the broadcast domain intact
  • Promiscuous mode is what a sniffer needs, and why a switched network does not help you

Terminology

Term Meaning
Frame The Layer 2 unit with a header and FCS
FCS / CRC Frame Check Sequence; detects, does not repair
CSMA/CD Carrier sense with collision detection; historical
Promiscuous mode Accept every frame, not just your own
MTU Largest frame payload a link carries
NIC The network interface card, and its MAC
BPDU Bridge Protocol Data Unit; STP frames
Frame flood Sending a frame to every port
NIC offload Kernel features that change what a sniffer sees

Field lab

Objective: read a real frame's fields by hand, and understand what promiscuous mode changes.

mkdir -p ~/aegis/labs/neso-n-2 && cd ~/aegis/labs/neso-n-2

# --- 1. capture and annotate one frame ---
sudo timeout 10 tcpdump -i lo -n -e -X -c 1 "icmp" 2>/dev/null | tee 01-frame.txt

# --- 2. decode it by hand ---
python3 - <<'PY' | tee 02-decode.txt
import struct
# A minimal Ethernet II + IPv4 + ICMP echo frame
eth = bytes.fromhex("0200000000020200000000010800")
ip  = bytes.fromhex("4500003c1c460000400101000a0a0a0aa0a0a0a01")
icmp= bytes.fromhex("080000e0d9045a3f00000100010000000000000000")
frame = eth + ip + icmp

print(f"  total frame: {len(frame)} bytes\n")
print("  --- ETHERNET (14 bytes) ---")
print(f"  dst MAC     : {frame[0:6].hex(':')}   (all zeros here: loopback)")
print(f"  src MAC     : {frame[6:12].hex(':')}")
print(f"  ethertype   : 0x{frame[12:14].hex()}  (0x0800 = IPv4)")
print()
print("  --- IPv4 (20 bytes) ---")
print(f"  version/ihl : {frame[14] >> 4}.{frame[14] & 0xf}")
print(f"  total len   : {struct.unpack('!H', frame[16:18])[0]}")
print(f"  ttl         : {frame[22]}")
print(f"  protocol    : {frame[23]}  (1 = ICMP)")
print(f"  src ip      : {'.'.join(map(str, frame[26:30]))}")
print(f"  dst ip      : {'.'.join(map(str, frame[30:34]))}")
print()
print("  --- ICMP ---")
print(f"  type/code   : {frame[34]}/{frame[35]}")
print(f"  checksum    : {frame[36:38].hex()}")
print()
print("  Every byte above is overhead the network paid to carry 8 bytes of ping.")

# --- 3. promiscuous mode, on your own interface only ---
{
  echo "=== before ==="
  ip link show lo | head -1
  sudo ip link set lo promisc on 2>/dev/null
  ip link show lo | head -1
  echo
  echo "  'PROMISC' in the flags means every frame is delivered to the host,"
  echo "  not just frames addressed to it. A sniffer needs this."
  sudo ip link set lo promisc off 2>/dev/null
  echo
  echo "=== restored ==="
  ip link show lo | head -1
} 2>&1 | tee 03-promisc.txt

# --- 4. NIC offload: why your captures look wrong ---
{
  echo "=== checksum / GRO offload (explains corrupt checksums in captures) ==="
  for i in /sys/class/net/*; do
    n=$(basename $i)
    printf "  %-8s rx-checksumming=%s tx-checksumming=%s gro=%s\n" "$n" \
      "$(cat $i/flags 2>/dev/null | grep -oE 'rx-checksumming' || echo off)" \
      "$(cat $i/flags 2>/dev/null | grep -oE 'tx-checksumming' || echo off)" \
      "$(cat $i/features 2>/dev/null | head -1 || echo n/a)"
  done
  echo
  echo "Offload means the checksum is computed after capture, so a pcap taken on"
  echo "a normal host shows 'bad' checksums. This is a capture artefact, not corruption."
  echo "Disable with: sudo ethtool -K eth0 rx off tx off gro off"
} 2>&1 | tee 04-offload.txt

# --- 5. frame volume: what a switch floods ---
{
  echo "=== frames seen on loopback in 5 seconds ==="
  a=$(cat /sys/class/net/lo/statistics/rx_packets)
  sleep 5
  b=$(cat /sys/class/net/lo/statistics/rx_packets)
  echo "  received: $((b - a)) packets in 5s"
  echo
  echo "=== and how many are distinct destinations (broadcasts included) ==="
  sudo timeout 6 tcpdump -i lo -n -e -c 50 2>/dev/null | awk '{print $NF}' | sort | uniq -c | sort -rn | head -5
} 2>&1 | tee 05-frames.txt
