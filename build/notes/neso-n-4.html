Network Layer: IP, Subnetting, Routing

Summary

The network layer's job is to move packets between networks. Its central design decision —
a connectionless, best-effort, header-based forwarding model — is exactly why it is the most
abused layer in security.

Key ideas

  • IP is connectionless: no setup, no acknowledgement, no guarantee of delivery or order
  • Best effort: packets may be dropped, duplicated, reordered, or corrupted in transit
  • Routing is per-hop: each router decides independently using longest-prefix match
  • Decentralised control is the internet's strength and its security weakness: no authority
    can revoke a spoofed source address, because nobody checks
  • Fragmentation happens here; a router that needs to fragment and cannot decrements TTL and
    sends ICMP "frag needed"
  • IPv4 header fields that matter: TTL, protocol, source, destination, options (which can
    hide data)

Terminology

Term Meaning
Connectionless No setup, no state kept per flow
Best effort No delivery guarantee
Hop-by-hop Decided independently at each router
Header The IPv4 header; fixed 20 bytes plus options
TTL Hop limit, prevents infinite loops
Fragmentation Splitting a packet to fit a smaller MTU
IP options Rarely-used header space; abused for covert channels
Routing table Destinations to next hops
Subnet mask Separates network from host bits
ARP (adjacent) Resolves the next hop's MAC

# --- 1. decode a header by hand ---
python3 - <<'PY' | tee 01-header.txt
import struct
# version, ihl, dscp/ecn, total len, id, flags/frag, ttl, proto, checksum, src, dst
raw = bytes.fromhex("4500003c1c460000400101000a0a0a0aa0a0a0a01")
v_ihl, dscp, tot, ident, flagsfrag, ttl, proto, csum = struct.unpack("!BBHHHBBH", raw[:12])
src = ".".join(map(str, raw[12:16])); dst = ".".join(map(str, raw[16:20]))
print(f"  version      : {v_ihl >> 4}")
print(f"  ihl          : {v_ihl & 0xf} words = {(v_ihl & 0xf) * 4} bytes")
print(f"  dscp/ecn     : {dscp:#04x}")
print(f"  total length : {tot}")
print(f"  id           : {ident}")
print(f"  flags/frag   : {flagsfrag:#06x}")
print(f"  ttl          : {ttl}   <- decremented by every router")
print(f"  protocol     : {proto}")
print(f"  checksum     : {csum:#06x}")
print(f"  source       : {src}")
print(f"  destination  : {dst}")
print()
print("  There is no checksum protecting the payload, and no signature on any")
print("  field. Every value in this header is attacker-controlled if the sender")
print("  chooses to lie.")
PY

# --- 2. TTL in action ---
python3 - <<'PY' | tee 02-ttl.txt
import socket, time
def ttl_probe(dst, ttl):
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    s.settimeout(1.0)
    try:
        s.setsockopt(socket.IPPROTO_IP, socket.IP_TTL, ttl)
        s.sendto(b"\x00\x00\x00\x00", (dst, 33434))
        s.recv(1024); return "reply"
    except socket.timeout: return "x"
    except OSError: return "!"
    finally: s.close()

target = "192.168.56.1"
print(f"  probing {target} with increasing TTL\n")
print("  ttl: " + "".join(f"{t:>4}" for t in range(1, 10)))
for t in range(1, 10):
    print(f"  {t:>3}: {ttl_probe(target, t):>4}", end="")
    print()
PY

# --- 3. fragmentation behaviour ---
{
  echo "=== payload sizes against the internet MTU ==="
  for sz in 1400 1472 1473 1500 2000; do
    r=$(ping -c1 -W2 -M do -s $sz 8.8.8.8 2>&1 | tail -1)
    printf "  -s %-5s %s\n" "$sz" "$r"
  done
  echo
  echo "1500 (MTU) - 20 (IP) - 8 (ICMP) = 1472 is the maximum."
  echo "Above that, a router must fragment - or drop and send ICMP 'frag needed'."
} 2>&1 | tee 03-frag.txt

# --- 4. IP options: a documented covert channel ---
cat > 04-ip-options.md <<'EOF'
# IP options as a covert channel

The IPv4 header is a fixed 20 bytes plus an optional `options` field, up to 40
bytes, marked by a non-zero IHL. Almost nothing on the internet interprets
those options. That makes them ideal for carrying data no middlebox inspects.

Lab-only construction:
```python
import struct
# option type 0x82 = loose source route (obsolete but still passed through
# by some stacks), with 4 bytes of your own payload
opt = bytes([0x82, 4]) + b"\xde\xad\xbe\xef"
ihl = (20 + len(opt)) // 4
ip = struct.pack("!BBHHHBBH4s4s", 0x40 | ihl, 0, 20+len(opt), 0, 0,
                 64, 6, 0, src, dst) + opt
```

Defence: strip IP options at the perimeter. Most networks never need them.
EOF
