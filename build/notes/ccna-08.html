OSPF, Routing Protocols and Troubleshooting

Summary

Dynamic routing: how routers learn paths instead of being configured one by one, and what an
attacker does to that conversation.

Key ideas

  • Static vs dynamic: static is safer and does not scale; dynamic converges automatically
  • IGP vs EGP: OSPF and RIP are interior (inside one AS); BGP is exterior (between ASes)
  • OSPF: link-state, areas, multicast 224.0.0.5/6, adjacency, LSA database. Runs on IP
  • Authentication exists (simple password, MD5, or cryptographic) — and is often absent
  • A neighbouring attacker can inject LSAs and steer traffic: a real routing attack
  • BGP is the internet's backbone; hijacking a prefix is a known, recurring incident type

Terminology

Term Meaning
IGP / EGP Interior / exterior gateway protocol
OSPF Open Shortest Path First; link-state IGP
Area OSPF grouping; all areas touch area 0
LSA Link State Advertisement — the unit of OSPF information
Cost OSPF's metric; derived from bandwidth
AS / ASN Autonomous System and its number
BGP Path-vector EGP; the internet's routing protocol
Prefix hijack Announcing someone else's address space
Convergence The time for all routers to agree

Field lab

Objective: read a routing table properly, and diagnose reachability the way a network
engineer (and an attacker) does.

mkdir -p ~/aegis/labs/ccna-08 && cd ~/aegis/labs/ccna-08

cat > troubleshoot.sh <<'EOF'
#!/usr/bin/env bash
# Ordered reachability diagnostics. Run it against a target in YOUR lab.
set -uo pipefail
T="${1:?usage: ./troubleshoot.sh <target>}"
say(){ printf '\n=== %s ===\n' "$*"; }

say "layer 3 identity of this host"
ip -br addr
ip route | head -5

say "is the target routable from here?"
ip route get "$T" 2>/dev/null || { echo "no route to $T"; exit 1; }

say "layer 2: can we even complete an ARP?"
GW=$(ip route | awk '/default/{print $3; exit}')
echo "  gateway: ${GW:-none}"
ip neigh show "$GW" 2>/dev/null || echo "  (no ARP entry for the gateway yet)"
ping -c1 -W1 "$GW" >/dev/null 2>&1 && echo "  gateway reachable" || echo "  gateway NOT reachable"
ip neigh show "$GW" 2>/dev/null

say "layer 3: ICMP"
ping -c3 -W2 "$T"

say "layer 3 with a large payload (MTU / fragmentation test)"
ping -c2 -W2 -s 1400 "$T" 2>/dev/null || echo "  1400-byte payload failed - fragmentation or MTU issue"

say "layer 3 with DF set (path MTU discovery)"
ping -c2 -W2 -M do -s 1472 "$T" 2>/dev/null || echo "  DF+1472 failed - a router on the path drops fragments"

say "path"
traceroute -n -w1 -q1 -m8 "$T" 2>/dev/null

say "layer 4: which ports answer"
for p in 22 53 80 443 445 3306; do
  timeout 2 bash -c "echo > /dev/tcp/$T/$p" 2>/dev/null && echo "  $p open" || echo "  $p closed/filtered"
done

say "summary"
echo "  Fill in: which layer failed first? That layer is your investigation."
EOF
chmod +x troubleshoot.sh

echo "=== run against yourself ==="
./troubleshoot.sh 127.0.0.1 2>&1 | tee 01-diagnose-self.txt

echo
echo "=== and against your lab, if built ==="
if ip -br addr show vboxnet0 >/dev/null 2>&1; then
  ./troubleshoot.sh 192.168.56.101 2>&1 | tee 02-diagnose-lab.txt
else
  echo "no lab yet - docs/LAB-SETUP.md" | tee 02-diagnose-lab.txt
fi

# --- the routing-security lesson ---
cat > 03-routing-attacks.md <<'EOF'
# Routing-layer attacks

## OSPF adjacency poisoning
1. Attacker on the segment sends OSPF Hello packets with a router ID of their choosing.
2. Without authentication, the real router forms an adjacency.
3. Attacker advertises LSAs claiming a shorter path (lower cost) to the destination network.
4. Traffic is directed through the attacker: a full MITM with no host compromise.

Defence: OSPF authentication (MD5 or better), passive interfaces on user ports,
area design that does not expose user-facing segments to adjacency.

## BGP prefix hijacking
An attacker announces another organisation's prefix from a network they legitimately operate.
Routers that accept it send traffic to the attacker.

Detection: route collectors and RPKI validation compare what is announced against what is
registered. Defence at the registry level, not the network level.

## The transferable lesson
Routing trusts *participation*. Every protocol that discovers neighbours by broadcasting is
trusting whoever answers first. That is the same shape as rogue DHCP and evil-twin WiFi.
EOF
cat 03-routing-attacks.md
