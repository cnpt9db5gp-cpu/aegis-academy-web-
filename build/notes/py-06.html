Sockets: Talking to Ports Directly

Summary

A socket is the kernel object a network connection maps to. Controlling it in Python gives you
total authority over what you send and receive — which is what reconnaissance, protocol analysis,
and understanding why tools behave the way they do all require.

This is the Tier 0 lecture that connects everything you have learned to actual network
interaction, and the conceptual gateway to Tier 2.

The lifecycle

socket() -> connect()  /  bind()+listen()+accept() -> send()/recv() -> close()
   |              |                                   |
 create      establish the link                   move the bytes
Client Server
create socket() socket()
address connect(host, port) bind((host,0)) then listen(backlog)
accept — accept() returns a new socket
exchange send/recv send/recv

accept() returning a new socket is the detail that trips people up: the listening socket
stays open for the next client; you work on the accepted one.

Reading a banner

import socket

def grab(host, port, timeout=2.0, limit=256):
    try:
        with socket.create_connection((host, port), timeout=timeout) as sock:
            sock.settimeout(timeout)
            return sock.recv(limit).decode("utf8", "replace").strip()
    except ConnectionRefusedError:
        return None      # closed
    except socket.timeout:
        return ""        # open but silent
    except OSError:
        return None

with closes the socket automatically, even on exception — same guarantee as files.

Writing an HTTP request yourself

def http_get(host, path="/", port=80):
    request = (
        f"GET {path} HTTP/1.1\r\n"
        f"Host: {host}\r\n"
        f"User-Agent: aegis/1.0\r\n"
        f"Connection: close\r\n"
        f"\r\n"
    )
    with socket.create_connection((host, port), timeout=3) as sock:
        sock.sendall(request.encode())
        chunks = []
        while True:
            data = sock.recv(4096)
            if not data:
                break
            chunks.append(data)
    return b"".join(chunks).decode("utf8", "replace")

Why not just use curl or requests?

  1. You learn what a client actually sends — headers, CRLF, the terminating blank line.
  2. You can send malformed requests on purpose, which is how request smuggling and header
    injection are tested.
  3. No dependency and no abstraction hiding what happens.

UDP: a different model

No handshake, no connection, no guarantee of delivery.

def udp_probe(host, port, payload=b"aegis-probe", timeout=1.0):
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sock.settimeout(timeout)
    try:
        sock.sendto(payload, (host, port))
        return sock.recvfrom(2048)
    except socket.timeout:
        return None, None     # ambiguous: closed, filtered, or slow
    finally:
        sock.close()

"No response" is inherently ambiguous for UDP. That is why -sU results are full of
open|filtered and UDP scanning is slow and unreliable.

Raw sockets and why they need root

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)                        # kernel builds headers
r = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_TCP)       # you build them

Raw sockets let you craft packets no ordinary library will emit: malformed headers, spoofed
sources, unusual flag combinations. They are why offensive tooling generally requires root — and
also why unprivileged users can still do most enumeration.

Timeouts, always

sock.settimeout(2.0)      # do this
sock.settimeout(None)     # blocks forever - almost never what you want

A scanner without timeouts hangs on the first filtered port. This is the single most common
bug in beginner network tooling.

Terminology

Term Meaning
Socket The kernel object a network endpoint maps to
IP:port pair What a socket is identified by
Bind Attach a socket to a specific address and port
Listen / backlog Mark a bound socket as accepting connections
Accept Return a new connected socket for one client
send vs sendall sendall guarantees all bytes are written
recv Read up to N bytes — may return fewer
Timeout Mandatory; without it, blocked reads hang
Banner The greeting a service sends on connect
Raw socket Kernel does not build headers; needs root
File descriptor The integer identifying an open socket

Field lab

Objective: write a socket-level scanner, send a hand-crafted HTTP request, and see the exact
bytes on the wire.

mkdir -p ~/aegis/labs/py-06 && cd ~/aegis/labs/py-06

cat > sockscan.py <<'PY'
import socket, sys, time, re

CONNECT_TIMEOUT = 2.0
RECV_TIMEOUT    = 1.5

def is_lab_address(host):
    try:
        p = socket.inet_aton(host)
        return (p[0] == 127 or p[0] == 10 or
                (p[0] == 172 and 16 <= p[1] <= 31) or
                (p[0] == 192 and p[1] == 168))
    except OSError:
        return False

def probe(host, port):
    # state: open | closed | filtered | dnsfail | error
    try:
        sock = socket.create_connection((host, port), timeout=CONNECT_TIMEOUT)
    except ConnectionRefusedError: return "closed", ""
    except socket.timeout:        return "filtered", ""
    except socket.gaierror:       return "dnsfail", ""
    except OSError as e:          return "error", type(e).__name__
    try:
        sock.settimeout(RECV_TIMEOUT)
        try:    banner = sock.recv(256).decode("utf8","replace").strip()
        except socket.timeout:      banner = ""
        except ConnectionResetError: banner = "<reset>"
        return "open", banner
    finally:
        sock.close()

def identify(banner):
    for pattern, name in [(r"^SSH-", "ssh"), (r"^220[- ].*FTP", "ftp"),
                          (r"^220[- ].*SMTP", "smtp"), (r"^HTTP/\d", "http"),
                          (r"^\* ", "telnet"), (r"^RFB \d", "vnc"),
                          (r"^\x05\xff", "smb"), (r"^220 MiNT", "mysql")]:
        if re.search(pattern, banner):
            return name
    return ""

def main(argv):
    if len(argv) < 2:
        print(f"usage: {argv[0]} <host> [port ...]", file=sys.stderr); return 2
    host = argv[1]
    if not is_lab_address(host):
        print(f"REFUSING {host}: outside loopback/RFC1918 scope.", file=sys.stderr)
        return 3
    ports = [int(a) for a in argv[2:]] or [21,22,23,25,80,443,3306,8080]
    started = time.time()
    print(f"{'PORT':<7}{'STATE':<10}{'SERVICE':<10}BANNER")
    print("-" * 70)
    tally = {}
    for port in ports:
        state, banner = probe(host, port)
        tally[state] = tally.get(state, 0) + 1
        print(f"{port:<7}{state:<10}{identify(banner) if state=='open' else '':<10}{banner[:44]}")
    print("-" * 70)
    print(f"{tally} in {time.time()-started:.2f}s")
    return 0

if __name__ == "__main__":
    sys.exit(main(sys.argv))

import socket
host, port = "127.0.0.1", 8080
req = ("GET / HTTP/1.1\r\nHost: 127.0.0.1:8080\r\n"
       "User-Agent: aegis/1.0\r\nAccept: */*\r\nConnection: close\r\n\r\n")
print("=== bytes we send (note CRLF and the terminating blank line) ===")
print(req.replace("\r\n", "\\r\\n\n"))
print("=== hexdump ===")
print(req.encode().hex())
try:
    with socket.create_connection((host, port), timeout=3) as s:
        s.sendall(req.encode())
        data = b""
        while chunk := s.recv(4096): data += chunk
    print("=== response ==="); print(data.decode("utf8","replace")[:800])
except OSError as e:
    print(f"no service on {host}:{port} ({type(e).__name__}) - start DVWA/Juice Shop first")
