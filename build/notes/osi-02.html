Passive Infrastructure Discovery and Subdomain Enumeration

Summary

One technique does most of the work in passive reconnaissance: certificate transparency. It
returns a complete, non-intrusive inventory of every hostname an organisation has ever had a
certificate for, including the ones they have since forgotten.

The framing: the goal is not the subdomain list. It is the host that
still exists and nobody owns. Enumeration is the mechanism.

Companion to tcm-02 (the operational workflow) and osi-01 (the
method). This note is the technique, in depth.

CT logs, and why they are the highest yield

  WHAT IT IS
    Before 2017, a CA could issue a certificate for a name without
    anyone being told. Certificate Transparency logs fixed that: every
    issuance is published to append-only logs that anyone can query.

  WHY IT IS A FINDING IN ITSELF
    A name you issued a certificate for is a name you wanted reachable
    OR a name someone tricked you into issuing for. Both are relevant,
    and the second one is how many takeovers happen: a subdomain
    points at a dead CNAME, the certificate is still valid, and
    someone claims the SaaS tenant.

  THE COST: ZERO. No packet reaches the target. No log entry. No
  rate limit. You are querying Google's public log index, not the
  target's web server.

  THE LIMITATIONS, honestly
    - it only covers names that had HTTPS. HTTP-only names are absent
    - it does not give you IPs. You resolve the names separately.
    - the log is the CA's record, so a mis-issued certificate for
      someone else's name appears too. Filter by the apex domain.
    - a wildcard cert (CN=*.example.com) appears as the literal
      string, not as every possible subdomain. That is a limitation
      of the source, not a bug.

# --- 1. the CT enumeration ---
cat > 01-ct.sh <<'EOF'
#!/usr/bin/env bash
# Certificate Transparency enumeration. PASSIVE: no packets reach the
# target's web services. This is querying a public log index.
DOMAIN="${1:?usage: ./01-ct.sh <domain>}"
mkdir -p raw
Q=$(python3 -c "import base64,sys;print(base64.b64encode(sys.argv[1].encode()).decode())" "$DOMAIN")
echo "=== CT LOGS for $DOMAIN ==="
curl -s --max-time 25 "https://crt.sh/?q=${Q}&output=json" -o "raw/crt-$DOMAIN.json" 2>/dev/null
python3 - "raw/crt-$DOMAIN.json" "$DOMAIN" <<'PY'
import json, sys, collections
path, domain = sys.argv[1], sys.argv[2].lower()
try: rows = json.load(open(path))
except Exception as e:
    sys.exit(f"  (crt.sh unreachable or returned non-JSON: {e})")
names, dates = set(), []
for r in rows:
    for n in (r.get("name_value") or "").split("\n"):
        n = n.strip().lower().lstrip("*.")
        if not n or "." not in n: continue
        if not (n == domain or n.endswith("." + domain)): continue   # apex filter
        names.add(n)
    if r.get("not_before"): dates.append(r["not_before"][:10])
print(f"\n  {len(rows)} certificate records")
print(f"  {len(names)} distinct hostnames under {domain}\n")
for n in sorted(names): print("   ", n)
print(f"\n  earliest issuance in the log: {min(dates) if dates else 'n/a'}")
print(f"  latest issuance in the log  : {max(dates) if dates else 'n/a'}")
# wildcards, which are a limitation worth stating
wc = [r.get("name_value") for r in rows if "*" in (r.get("name_value") or "")]
if wc: print(f"\n  {len(wc)} records are WILDCARD certificates.")
print("    ^ a wildcard cert does not enumerate subdomains. Anything")
print("      you find for those must come from another source.")
PY
EOF
chmod +x 01-ct.sh

From a name list to a target list

cat > 03-resolve.py <<'PY'
#!/usr/bin/env python3
"""Turn a name list into a target list, and RANK it.

The point of this script is the ranking. A list of 200 hostnames
resolving is not intelligence. Four of them resolving, unowned, to a
range the organisation still holds, IS intelligence.
"""
import socket, sys, json, collections
from datetime import datetime, timezone

def resolve(host, timeout=3):
    try:
        infos = socket.getaddrinfo(host, None, proto=socket.IPPROTO_TCP)
        return sorted({i[4][0] for i in infos})
    except Exception:
        return []

def main(names_file, out_file):
    names = [n.strip() for n in open(names_file) if n.strip()]
    results = {}
    for n in names:
        results[n] = resolve(n)

    # group by IP, because several names on one IP is a finding
    by_ip = collections.defaultdict(list)
    for n, ips in results.items():
        for ip in ips: by_ip[ip].append(n)

    now = datetime.now(timezone.utc).isoformat()
    ranked = []
    for ip, hosts in by_ip.items():
        score, reasons = 0, []
        if len(hosts) > 1:
            score += 3
            reasons.append(f"{len(hosts)} names on one IP ({', '.join(hosts[:4])})")
        for h in hosts:
            if h.startswith(("admin","vpn","remote","gateway","portal",
                            "legacy","old","test","staging","dev","backup",
                            "intranet","owa","exchange","sql","db","jenkins",
                            "gitlab","jira","monitor","grafana","kibana")):
                score += 2
                reasons.append(f"high-value name: {h}")
                break
        if ip.startswith(("127.","0.")):
            score -= 5; reasons.append("loopback (a dangling CNAME)")
        ranked.append((score, ip, hosts, reasons))
    ranked.sort(reverse=True)

    print(f"  {len(names)} names, {len(results)} resolved, "
          f"{len(by_ip)} distinct addresses\n")
    print(f"  {'SCORE':<6} {'ADDRESS':<17} NAMES")
    print("  " + "-"*78)
    for score, ip, hosts, reasons in ranked[:25]:
        print(f"  {score:<6} {ip:<17} {', '.join(hosts[:3])}"
              f"{' ...' if len(hosts)>3 else ''}")
        for r in reasons[:2]: print(f"         - {r}")

    json.dump({"observed_at": now, "by_ip":
               {ip: hosts for _, ip, hosts, _ in ranked}},
              open(out_file, "w"), indent=2)
    print(f"\n  written: {out_file}")

if __name__ == "__main__":
    if len(sys.argv) < 3:
        print(__doc__); print("usage: 03-resolve.py names.txt out.json")
        sys.exit(0)
    main(sys.argv[1], sys.argv[2])
PY
echo "written: 03-resolve.py"

Step 3 is the deliverable: 03-resolve.py turns a name list into a ranked target list.
Four hostnames on one IP, or a name like legacy or jenkins, scores higher than fifty lone
subdomains — because 200 resolved hostnames is not intelligence, while four that resolve to a
range the organisation still owns is.

01-ct.sh enforces the discipline: it filters by apex domain (because CT logs include
certificates mis-issued for other people's names in yours), and it explicitly states the
limitation that a wildcard certificate does not enumerate subdomains.

Record: 01-ct.sh and 03-resolve.py.
