Functions, Decomposition, and Scope

Summary

Functions are how you stop rewriting the same thing, and how you make a concept nameable — which
matters in security because naming a concept is how you reason about it.

The design idea that matters most is decomposition: break a problem into pieces that each do
exactly one thing.

Defining and calling

def greet(name):
    return f"hello {name}"

def connect(host, port=22, timeout=5):
    ...

connect("127.0.0.1", 2222)           # positional
connect("127.0.0.1", port=2222)     # keyword - clearer, prefer this

The mutable-default bug — it bites everyone once

def append(item, lst=[]):     # BAD: created ONCE, shared by every call
    lst.append(item)
    return lst

append(1); append(2)
print(append(3))              # [1, 2, 3] - not [3]

def append(item, lst=None):   # correct
    if lst is None:
        lst = []
    lst.append(item)
    return lst

Where this bites in security: a default argument holding a mutable buffer, session object, or
request state becomes shared across every call — a real source of data leaking between
requests.

Multiple return values

def check_port(host, port):
    return True, "SSH-2.0-OpenSSH_9.2"      # a tuple

is_open, banner = check_port("127.0.0.1", 22)

Use a tuple for a fixed small record, a dict when the shape is open-ended.

Scope: LEGB

Local -> Enclosing -> Global -> Built-in

count = 0                        # global

def outer():
    msg = "enclosing"
    def inner():
        print(count, msg, len)  # found in global, enclosing, builtin
        local_var = 1            # this is LOCAL to inner
    inner()

Rule: assigning inside a function makes that name local for the whole function body.

n = 10
def broken():
    print(n)      # UnboundLocalError - n is local from the assignment below
    n = 20
broken()

Python decides this at compile time by seeing the assignment, not at runtime. It surprises
everyone once.

Decomposition: the actual skill

# BAD - one function doing four things
def scan_and_exploit():
    ...  # 80 lines of sockets, parsing, printing and exploitation

# BETTER - each function names one idea
def tcp_connect(host, port, timeout=3.0):
    """Open a TCP connection. Returns a socket or None."""
    ...

def read_banner(sock, limit=256):
    """Read up to `limit` bytes of banner."""
    ...

def identify(banner):
    """Turn a banner into a service name."""
    ...

def scan_host(host, ports):
    """Scan many ports, return a list of result dicts."""
    results = []
    for port in ports:
        sock = tcp_connect(host, port)
        if sock:
            results.append({"port": port, "banner": read_banner(sock)})
            sock.close()
    return results

Now every function is independently testable, readable, and replaceable. This is the most
transferable habit in the lecture.

Command-line entry points

import sys

def main(argv):
    if len(argv) < 2:
        print(f"usage: {argv[0]} <target>", file=sys.stderr)
        return 2                 # a real exit code
    return scan(argv[1])

if __name__ == "__main__":
    sys.exit(main(sys.argv))

if __name__ == "__main__": lets the file be imported (to reuse its functions) or
executed (to run as a CLI). Every serious tool has it, and it is what makes the lab's reuse
step possible.

Terminology

Term Meaning
Function Named reusable block with parameters and a return value
Parameter / argument Declaration name / value passed in
Scope (LEGB) Local, Enclosing, Global, Built-in lookup order
global / nonlocal Rebind a name from an outer scope
Mutable default def f(x=[]) — evaluated once, shared forever
Decomposition Splitting into single-purpose functions
Side effect Changing something outside the function
Docstring The string literal under def documenting intent
__name__ "__main__" when executed, module name when imported

Field lab

Objective: build a decomposed network utility with an enforced scope guard.

mkdir -p ~/aegis/labs/py-02 && cd ~/aegis/labs/py-02

cat > netscan.py <<'PY'
#!/usr/bin/env python3
# netscan - a decomposed TCP port scanner.
# Each function does exactly one thing. Loopback and authorised lab ranges only.
import socket, sys, time

TIMEOUT = 2.0

def tcp_connect(host, port, timeout=TIMEOUT):
    # Returns a socket on success, None on failure.
    try:
        return socket.create_connection((host, port), timeout=timeout)
    except (ConnectionRefusedError, socket.timeout, OSError):
        return None

def read_banner(sock, limit=256):
    # Read up to `limit` bytes of banner without blocking forever.
    try:
        sock.settimeout(1.0)
        return sock.recv(limit).decode("utf8", "replace").strip()
    except (socket.timeout, OSError):
        return ""

def identify(banner):
    # Map a banner to a service name using prefix matching.
    if not banner:
        return "unknown"
    for prefix, name in [("SSH-", "ssh"), ("220 ProFTPD", "ftp"),
                         ("HTTP/1", "http"), ("HTTP/2", "http"),
                         ("* ", "telnet"), ("RFB", "vnc")]:
        if banner.startswith(prefix):
            return name
    return "unknown"

def is_lab_address(host):
    # Refuse anything outside loopback and RFC1918 private space.
    try:
        p = socket.inet_aton(host)
        if p[0] == 127: return True
        if p[0] == 10: return True
        if p[0] == 172 and 16 <= p[1] <= 31: return True
        if p[0] == 192 and p[1] == 168: return True
    except OSError:
        return False
    return False

def scan_host(host, ports):
    # Scan a list of ports. Returns a list of result dicts.
    results = []
    for port in ports:
        started = time.time()
        sock = tcp_connect(host, port)
        if sock is None:
            continue
        banner = read_banner(sock)
        sock.close()
        results.append({"port": port, "service": identify(banner),
                        "banner": banner[:80],
                        "ms": int((time.time() - started) * 1000)})
    return results

def main(argv):
    if len(argv) < 2:
        print(f"usage: {argv[0]} <host> [port ...]", file=sys.stderr)
        return 2
    host = argv[1]
    if not is_lab_address(host):
        print(f"REFUSING {host}: not loopback or RFC1918. "
              f"See docs/RULES-OF-ENGAGEMENT.md", file=sys.stderr)
        return 3
    ports = [int(a) for a in argv[2:]] or [22, 80, 443, 8080, 3306, 5432]
    print(f"scanning {host}: {ports}\n")
    rows = scan_host(host, ports)
    if not rows:
        print("  no open ports found")
        return 0
    print(f"{'PORT':<7}{'SERVICE':<10}{'MS':<7}BANNER")
    print("-" * 60)
    for r in rows:
        print(f"{r['port']:<7}{r['service']:<10}{r['ms']:<7}{r['banner']}")
    return 0

if __name__ == "__main__":
    sys.exit(main(sys.argv))

Step 3 matters most. The scanner refuses to touch anything outside private space. Copy that
guard into every tool you write.

Step 5 is the payoff. You wrote a tool other programs can import. That is how impacket,
scapy and metasploit are built.
