Evidence, Timeline and Detection Review

Summary

Capstone stage four is the forensic one: you have the objective, and now you have to prove the
path, timeline it, and say what the client's monitoring would or would not have caught.

The framing: the objective was getting the shell. This stage is
proving how, showing when, and — the part most testers skip — whether
anyone would have noticed.

Companion to for-01..for-07 (the methodology) and ad-08 (AD
detection). This note is the capstone's forensic deliverable.

The four deliverables

  1. EVIDENCE PACKAGE   every artefact, hashed, with provenance
  2. TIMELINE            the sequence, with the sources it came from
  3. ARTEFACT CHECK      what you left behind, and how you verified
                        it is gone
  4. DETECTION REVIEW    which of your actions would have generated an
                        alert, and which would have been invisible

  THE FOURTH IS WHAT DISTINGUISHES THIS STAGE. Anyone can produce a
  timeline. Saying "the SMB relay generated no event on the domain
  controller at all, and the Kerberoasting generated only 4769
  requests to the KDC, which the client's audit policy does not log"
  is a finding the client cannot get from anyone else.

#!/usr/bin/env python3
"""Hash and record provenance for every artefact in the evidence tree.

Run this at the END of the engagement, not the beginning. The point is
to record what exists so the report's claims can be checked.
"""
import hashlib, pathlib, json, datetime, sys

def sha256(p, chunk=1 << 20):
    h = hashlib.sha256()
    with open(p, "rb") as f:
        for b in iter(lambda: f.read(chunk), b""): h.update(b)
    return h.hexdigest()

def main(root, out):
    root = pathlib.Path(root)
    rows = []
    for p in sorted(root.rglob("*")):
        if not p.is_file(): continue
        if p.name == out: continue
        st = p.stat()
        rows.append(dict(
            path=str(p.relative_to(root)),
            bytes=st.st_size,
            sha256=sha256(p),
            mtime_utc=datetime.datetime.fromtimestamp(
                st.st_mtime, datetime.timezone.utc).isoformat()))
    doc = {"generated": datetime.datetime.now(datetime.timezone.utc).isoformat(),
           "root": str(root), "count": len(rows), "files": rows}
    pathlib.Path(out).write_text(json.dumps(doc, indent=2))
    print(f"  {len(rows)} files hashed -> {out}\n")
    for r in rows[:25]:
        print(f"  {r['sha256'][:16]}...  {r['bytes']:>9}  {r['path']}")
    if len(rows) > 25: print(f"  ... and {len(rows)-25} more")
    return doc

if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else "evidence",
         sys.argv[2] if len(sys.argv) > 2 else "evidence/MANIFEST.json")

       "evidence/raw/cleanup.txt", "confirmed"),
 (210, "authorisation",  "tester",   "engagement ended",
       "00-AUTHORISATION.md", "confirmed"),
]

def render(events, t0):
    out = []
    out.append("  " + "="*96)
    out.append("  CAPSTONE TIMELINE  (all times UTC; the lab DC's clock is the reference)")
    out.append("  " + "="*96)
    cur = None
    for off, src, actor, action, artefact, conf in events:
        ts = t0 + timedelta(minutes=off)
        if src != cur:
            out.append("")
            out.append(f"  --- source: {src} " + "-"*(70-len(src)))
            cur = src
        flag = "" if conf == "confirmed" else f"  [{conf}]"
        out.append(f"  {ts:%H:%M}  {actor:<11} {action}{flag}")
        out.append(f"          evidence: {artefact}")
    out.append("")
    out.append("  " + "-"*96)
    out.append(f"  {len(events)} events across "
               f"{len({e[1] for e in events})} distinct sources, over "
               f"{(events[-1][0])//60}h{(events[-1][0])%60}m")
    return "\n".join(out)

if __name__ == "__main__":
    print(render(EVENTS, T0))
    pathlib.Path("timeline/capstone-timeline.txt").write_text(render(EVENTS, T0))

The detection review, which is the part nobody asks for

cat > 05-detection.py <<'PY'
#!/usr/bin/env python3
"""For each action taken, what would the client's monitoring have seen?

The honest answer is frequently "nothing", and that is the finding.
"""
ACTIONS = [
 # (action, tier, AD events, host events, would_an_alert_fire)
 ("Anonymous LDAP bind + full enumeration", "ad-03",
  ["(none - anonymous binds are not logged by default)"], [],
  "NO. Unless the DC has verbose LDAP logging, which most do not."),
 ("AS-REP request for a preauth-disabled account", "ad-04",
  ["4769 Kerberos service ticket operation, or 4768 for the TGT"],
  [],
  "MAYBE. 4768/4769 need 'Audit Kerberos Authentication Service' with "
  "Success enabled, which is NOT the default. Most environments do not "
  "have it, so this roast is invisible."),
 ("TGS-REQ for a service ticket (Kerberoasting)", "ad-04",
  ["4769, one per request", "4624 only when the ticket is USED"],
  [],
  "NO, at the roast stage. The requests are logged only if 4769 is on. "
  "The USE of the cracked password generates 4768, which is more commonly "
  "audited - but by then the attack has succeeded."),
 ("Cracking the hash offline", "cry-d4",
  [], [],
  "NO. There is no server contact. The attacker is attacking a string "
  "they already have, on their own hardware, with no rate limit."),
 ("Pass-the-hash over SMB", "ad-04 / imp-02",
  ["4624 logon type 3", "4672 if privileges assigned"],
  ["4624 type 3", "7045 if a service was created (psexec)"],
  "PARTLY. The logon is there if the DC logs 4624 (common). It looks "
  "like an ordinary network logon from a workstation on the LAN. "
  "Without a source-IP alert it is indistinguishable from normal."),
 ("LDAP write: adding a user to a group", "ad-05",
  ["5136 directory object modified"],
  [],
  "YES, if Advanced Audit Policy > DS Access > Directory Service Changes "
  "is set to Success. This is NOT on by default on most systems. "
  "This is the single cheapest detection improvement in the report."),
 ("DCSync", "ad-05",
  ["4662 Directory Service Access with one of the three replication GUIDs",
   "4663 Attempt to enumerate the DS, once per object",
   "5136 where anything is modified"],
  [],
  "YES, if Audit Directory Service Access is enabled (default: Success "
  "and Failure on Domain Controllers, but NOT on member servers). "
  "This is the highest-fidelity detection available and it is a single "
  "GPO."),
 ("Database read on SRV01", "-",
  [], ["MSSQL login event", "SQL audit"],
  "DEPENDS ENTIRELY ON THE APP. Most applications do not audit database "
  "reads at all. This is a finding about the client, not about you."),
 ("Removing the group membership (cleanup)", "-",
  ["5136 directory object modified"],
  [],
  "YES, if 5136 is on. Your cleanup is as detectable as your attack, "
  "which is why the timeline above records it separately."),
]

def render():
    w = 100
    print("  " + "="*w)
    print("  DETECTION REVIEW: what the client's monitoring would have seen")
    print("  " + "="*w)
    counts = {"YES":0, "MAYBE":0, "PARTLY":0, "NO":0, "DEPENDS":0}
    for action, tier, ad, host, verdict in ACTIONS:
        print(f"\n  ACTION: {action}   [{tier}]")
        print(f"    AD events   : {', '.join(ad) if ad else 'none'}")
        print(f"    Host events : {', '.join(host) if host else 'none'}")
        print(f"    WOULD AN ALERT FIRE?  {verdict}")
        counts[verdict.split()[0].rstrip(':')] = \
            counts.get(verdict.split()[0].rstrip(':'), 0) + 1
    print("\n  " + "-"*w)
    print("  SCOREBOARD")
    for k, v in counts.items():
        print(f"    {k:<10} {v} of {len(ACTIONS)} actions")
    print()
    print("  THE HEADLINE, and it is the finding:")
    print("    The DCSync - the moment of domain compromise - was detectable.")
    print("    The Kerberoasting that preceded it, which took four minutes and")
    print("    recovered a privileged service account password, was NOT.")
    print("    And the offline cracking was not detectable at all, because there")
    print("    is no server to detect it on.")
    print()
    print("  So the client's detection would have fired AFTER the attack had")
    print("  already succeeded, if it fired at all.")
    print()
    print("  THE TWO RECOMMENDATIONS THAT FOLLOW, in order:")
    print("    1. Enable Advanced Audit Policy > DS Access > 'Audit Directory")
    print("       Service Changes' = Success. One GPO. Catches the group write.")
    print("    2. Enable 'Audit Kerberos Authentication Service' = Success, and")
    print("       alert on 4768/4769 from a source that is not a domain")
    print("       controller. Catches the roast.")
    print()
    print("  Both are configuration. Neither requires a purchase. That is why")
    print("  they are the recommendations.")

if __name__ == "__main__":
    render()

Step 5 is the capstone's real deliverable, and the scoreboard is the finding: the DCSync —
the moment of domain compromise — was detectable. The Kerberoasting that preceded it, which
took four minutes and recovered a privileged service account password, was not. And the
offline cracking was not detectable at all, because there is no server to detect it on.

So the client's detection would have fired after the attack had already succeeded. The two
recommendations that follow are both a single GPO and neither requires a purchase.
