Reconnaissance and Attack Surface Mapping

Summary

Capstone stage one. Everything passive first, then active, then the map — and the map is the
deliverable, not the reconnaissance itself.

The framing: recon ends when you can name the attack surface and
say, for each part of it, how a person reaches it. Everything before
that is gathering.

The order, and why it is that order

  1. PASSIVE / OSINT (osi-01..osi-03)
     zero footprint. Certificate transparency, DNS, public code,
     documents. Establishes the estate before anyone logs anything.

  2. THE GROUND TRUTH (ad-03)
     the anonymous LDAP surface. If anonymous bind is open, a
     meaningful part of recon needs no credentials at all.
     Run this BEFORE the credentialed recon: it tells you what the
     credentialed recon is even for.

  3. ACTIVE DISCOVERY (tcm-03)
     host discovery, then ports, then versions, then scripts.
     One host at a time, low rate, with the scope guard on every call.

  4. ENUMERATION, PER SERVICE
     what is this thing, and what does it expose beyond its port.

  5. THE MAP
     every asset, every service, every identity, every edge between
     them - and for each, HOW SOMEONE REACHES IT.

  WHY THIS ORDER:
    - it means the loud part is as late and as narrow as possible
    - it means you know what to look for before you look
    - and stage 2 tells you whether stages 3 and 4 need credentials
      at all, which changes how loud they have to be

#!/usr/bin/env bash
# Stage 1. PASSIVE. Zero packets to the target's services.
# Only loopback services on the lab host are touched, and only to
# record what is already there.
T="recon/passive"

echo "=== 1. the estate as this host already knows it ==="
{
  echo "observed: $(date -u +%Y-%m-%dT%H:%M:%SZ)"
  echo "host: $(hostname)"
  echo
  echo "--- my own addresses (the ground truth you sit on) ---"
  ip -br a
  echo
  echo "--- my own DNS config ---"
  cat /etc/resolv.conf | grep -v "^#" | grep .
  echo
  echo "--- what I can reach on loopback ---"
  ss -tulpn state listening 2>/dev/null | awk 'NR>1{print "  "$1, $5, $7}'
  echo
  echo "--- the routes that exist ---"
  ip route
  echo
  echo "NOTE the default route. That is the host's REAL lan. It is"
  echo "out of scope (cap-01's 192.168.1.0/24 entry). Nothing in this"
  echo "engagement may traverse it."
} | tee "$T/host.txt"

echo
echo "=== 2. the lab AD, anonymously (stage 2) ==="
DC="192.168.56.10"
if command -v ldapsearch >/dev/null; then
  NC=$(ldapsearch -x -H "ldap://$DC" -b "" -s base defaultNamingContext 2>/dev/null \
       | grep -m1 "^defaultNamingContext:" | awk '{print $2}')
  if [ -n "$NC" ]; then
    {
      echo "observed: $(date -u +%Y-%m-%dT%H:%M:%SZ)"
      echo "naming context: $NC"
      echo
      echo "--- THE FINDING: anonymous bind is open ---"
      ldapsearch -x -H "ldap://$DC" -b "" -s base \
        namingContexts supportedLDAPVersion dnsHostName \
        forestFunctionalityLevel domainFunctionalityLevel 2>/dev/null \
        | grep -E "^[a-zA-Z]+:" | sed 's/^/  /'
      echo
      echo "--- enabled users (no credentials used) ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" \
        "(&(objectCategory=person)(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=512))" \
        sAMAccountName 2>/dev/null | grep "^sAMAccountName:" | sed 's/^/  /'
      echo
      echo "--- computers ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" "(objectCategory=computer)" \
        dNSHostName operatingSystem 2>/dev/null | grep -E "^[a-zA-Z]+:" | sed 's/^/  /'
      echo
      echo "--- accounts with SPNs (the Kerberoasting list) ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" \
        "(&(objectCategory=person)(objectClass=user)(servicePrincipalName=*))" \
        sAMAccountName servicePrincipalName msDS-SupportedEncryptionTypes 2>/dev/null \
        | grep -E "^(sAM|service|msDS)" | sed 's/^/  /'
      echo
      echo "--- ACCOUNTS WITH PREAUTH DISABLED (AS-REP roastable, FREE) ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" \
        "(userAccountControl:1.2.840.113556.1.4.803:=1048576)" \
        sAMAccountName 2>/dev/null | grep "^sAMAccountName:" | sed 's/^/  /'
      echo "  ^ found with NO credentials. Each one is a finding."
      echo
      echo "--- delegation attributes ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" "(msDS-AllowedToDelegateTo=*)" \
        sAMAccountName msDS-AllowedToDelegateTo 2>/dev/null \
        | grep -E "^(sAM|msDS)" | sed 's/^/  /'
      echo
      echo "--- group memberships, fully transitive ---"
      ldapsearch -x -H "ldap://$DC" -b "$NC" "(objectCategory=group)" \
        sAMAccountName member 2>/dev/null \
        | grep -E "^(sAM|member):" | sed 's/^/  /'
    } | tee "$T/ldap-anonymous.txt"
  else
    echo "  anonymous bind refused, or no DC at $DC. Record which."
  fi
else
  echo "  ldapsearch not installed: sudo apt install ldap-utils"
fi
EOF
chmod +x 01-passive.sh
./01-passive.sh 2>&1 | head -50 | tee 02-passive.txt

cat > 03-map.py <<'PY'
#!/usr/bin/env python3
"""The attack surface map.

The deliverable of recon is not the recon output. It is this: every
asset, every service, every identity, and for each - HOW SOMEONE
REACHES IT. Anything without a reachability path is inventory.
"""
import json, sys, pathlib

def build(ad_hosts, external_range, internal_range, users, spns,
          preauth_off, delegation, groups, services):
    assets = []
    for ip, name, role, ranges in ad_hosts:
        assets.append(dict(ip=ip, name=name, role=role, ranges=ranges,
                           reachable_from=(["anywhere in the lab"]
                                           if external_range in ranges
                                           else ["via a pivot only"]),
                           type="AD asset"))
    for ip, ports, notes in services:
        assets.append(dict(ip=ip, type="service", ports=ports, notes=notes))

    lines, cur = [], None
    def sec(t):
        nonlocal cur
        lines.append(("H", t)); cur = []

    sec("HOSTS")
    for a in assets:
        if a["type"] != "AD asset": continue
        lines.append(("L", f"{a['ip']:<16} {a['name']:<8} {a['role']}"))
        lines.append(("L", f"{'':<16} reachable: {', '.join(a['reachable_from'])}"))

    lines.append(("H", "IDENTITIES"))
    for u in users:
        gs = groups.get(u, [])
        lines.append(("L", f"{u:<16} {', '.join(gs) if gs else 'no group membership'}"))

    lines.append(("H", "THE THREE ATTACK SURFACES (each with its reachability)"))
    surfaces = []
    if spns:
        surfaces.append(("SPN / Kerberoasting",
            "any authenticated user (or anonymous, for preauth-off accounts)",
            ", ".join(spns), "ad-04"))
    if preauth_off:
        surfaces.append(("Preauth disabled / AS-REP roasting",
            "ANYONE WHO CAN REACH PORT 88 - no credentials",
            ", ".join(preauth_off), "ad-04"))
    if delegation:
        surfaces.append(("Unconstrained delegation",
            "any user who logs in to the delegated host",
            ", ".join(delegation), "ad-02"))
    for s in services:
        for port, note in s[1]:
            if port in (445, 139, 88, 389, 5985, 3389, 8080):
                surfaces.append((f"{note} on port {port}",
                    "internal network" if s[0].startswith("192.168.56") else "internal only",
                    s[0], "ad-06"))
    for name, reach, targets, ref in surfaces:
        lines.append(("L", f"{name}"))
        lines.append(("L", f"    reachable by : {reach}"))
        lines.append(("L", f"    applies to    : {targets}"))
        lines.append(("L", f"    technique     : {ref}"))

    lines.append(("H", "THE PATHS, AND WHICH IS SHORTEST"))
    paths = [
      ["anonymous LDAP", "enumerate svc-legacy (preauth off)", "AS-REP roast",
       "recover svc-legacy's password", "log in as svc-legacy"],
      ["anonymous LDAP", "enumerate SPNs", "Kerberoast svc-backup (RC4)",
       "recover svc-backup's password", "it is in Backup Operators",
       "escalate to Domain Admin"],
      ["authenticated as alice", "alice is in helpdesk",
       "GenericAll on IT Support", "add alice to IT Support",
       "GenericWrite on svc-web", "set an SPN, roast it",
       "svc-web is in a privileged group"],
      ["access to WEB01", "WEB01 has unconstrained delegation",
       "wait for a user to log in", "capture their forwarded TGT",
       "use the TGT as that user"],
    ]
    for p in paths:
        lines.append(("L", ""))
        lines.append(("L", "PATH (" + str(len(p)) + " hops):"))
        for i, step in enumerate(p, 1):
            lines.append(("L", f"    {i}. {step}"))

    w = 62
    print(f"  {'ATTACK SURFACE MAP':<{w}}")
    print("  " + "="*w)
    for kind, text in lines:
        print(f"  {text}" if kind == "L" else f"\n  {text}\n  " + "-"*w)
    return {"assets": assets,
            "identities": users, "spns": spns,
            "preauth_disabled": preauth_off, "delegation": delegation,
            "generated": "recon"}

if __name__ == "__main__":
    build(
      ad_hosts=[("192.168.56.10", "DC01", "domain controller", ["192.168.56.0/24","10.10.10.0/24"]),
                ("192.168.56.11", "DC02", "domain controller", ["192.168.56.0/24","10.10.10.0/24"]),
                ("192.168.56.20", "WKS01", "unprivileged workstation", ["192.168.56.0/24"]),
                ("192.168.56.21", "WKS02", "privileged workstation", ["192.168.56.0/24"]),
                ("10.10.10.20", "SRV01", "app + file server", ["10.10.10.0/24"])],
      external_range="192.168.56.0/24", internal_range="10.10.10.0/24",
      users=["alice","bob","erin","svc-backup","svc-legacy","svc-web","svc-iis"],
      spns=["svc-backup (HOST/dc01, RC4)","svc-web (HTTP/web01, RC4)","svc-iis (HTTP/web02, AES)"],
      preauth_off=["svc-legacy"],
      delegation=["WEB01 (msDS-AllowedToDelegateTo = ALL)"],
      groups={"alice":["helpdesk"],"bob":["helpdesk"],"erin":["IT Support"],
              "svc-backup":["Backup Operators"],"svc-web":["Helpdesk Operators"],
              "svc-iis":["IIS_IUSRS"]},
      services=[("192.168.56.10",[(88,"Kerberos"),(389,"LDAP"),(445,"SMB"),
                                   (5985,"WinRM"),(3389,"RDP")],"Domain controller"),
                ("10.10.10.20",[(445,"SMB"),(1433,"MSSQL"),(80,"HTTP")],"App + file")])
PY

Stop conditions for this stage

  STOP IMMEDIATELY IF:

  - a scan would touch an address outside 192.168.56.0/24 or
    10.10.10.0/24. The guard enforces this, but read what it prints.

  - you find an asset that is not in the plan. An unplanned host
    means either the plan was wrong or something is not what you
    think it is. Find out which BEFORE scanning it.

  - you find data that looks like it should not be there. Real
    personal data in a lab means the lab is connected to something
    real. Stop and check.

  - the volume of traffic is producing an operational effect on the
    lab. Back off the rate. A lab host is usually a laptop.

  DO NOT STOP FOR:
  - a finding you did not expect. Write it down, keep going.
  - a service that is more exposed than the plan assumed. That is
    the exercise working.
