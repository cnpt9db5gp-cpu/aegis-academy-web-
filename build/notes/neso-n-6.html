Application Layer: DNS, DHCP, HTTP, SMTP

Summary

Where data becomes meaningful. Application-layer protocols are what you actually test, and they
are overwhelmingly cleartext.

Key ideas

  • DNS names, DHCP configures, HTTP transfers, SMTP sends
  • Most of it is plaintext: HTTP, FTP, Telnet, POP3, IMAP, SMTP — and SNMP v1/v2c
  • TLS adds encryption and server authentication; it does not add user authentication
  • HTTP semantics: stateless, verbs, status codes, headers, cookies. Everything in Tier 4
    is a misbehaviour of one of those
  • SMTP is a conversation, not a transaction: the server speaks first
  • Encrypted variants exist for all of them and are almost always used in practice

Terminology

Term Meaning
Protocol An agreed message format at the application layer
Cleartext Readable without decryption
Request / response The HTTP pattern
Stateless Each request stands alone; sessions are simulated by cookies
Status code 1xx-5xx; the first digit is the class
Header Metadata preceding the body
Verb / method GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
Banner The first thing a service says
TLS Encryption and server authentication in transit
Well-defined vs ad hoc Protocol rigor versus something improvised

# --- 1. HTTP, written by hand in Python (no library) ---
python3 - <<'PY' | tee 01-http.txt
import socket
def raw_get(host, port, path="/", host_header=None):
    host_header = host_header or (f"{host}:{port}" if port != 80 else host)
    req = (f"GET {path} HTTP/1.1\r\nHost: {host_header}\r\n"
           f"User-Agent: aegis/1.0\r\nConnection: close\r\n\r\n")
    with socket.create_connection((host, port), timeout=3) as s:
        s.sendall(req.encode())
        data = b""
        while chunk := s.recv(4096):
            data += chunk
    head, _, body = data.partition(b"\r\n\r\n")
    return head.decode("utf8","replace"), body

for port in (8080, 80):
    try:
        head, body = raw_get("127.0.0.1", port)
        print(f"  --- {host if False else '127.0.0.1'}:{port} ---")
        print("  " + "\n  ".join(head.splitlines()[:8]))
        print(f"  body: {len(body)} bytes")
        print()
        break
    except OSError as e:
        print(f"  {port}: {type(e).__name__}")
PY

# --- 2. the status code classes, and why they matter for reporting ---
cat > 02-status.txt <<'EOF'
HTTP status classes - and what each one tells an assessor

1xx  informational     request received, continuing
2xx  success           200 OK, 201 Created, 204 No Content, 206 Partial
3xx  redirection       301 moved permanently, 302 found, 304 not modified,
                        307/308 preserve method (unlike 302)
4xx  client error      the REQUESTER is wrong
      400 bad request        malformed syntax
      401 unauthorized       needs authentication (different from 403)
      403 forbidden          understood but refused
      404 not found          absent - or deliberately disguised
      405 method not allowed  the verb is wrong for this resource
      429 too many requests   you are being rate limited
5xx  server error      the SERVER is wrong
      500 internal error     often leaks a stack trace
      502 bad gateway        an upstream failed
      503 unavailable        overloaded or down

Reporting notes:
- 200 on a login page that should be 302 = the authentication check is missing
- 404 vs 403 difference reveals whether a resource exists
- 405 means the endpoint exists and is simply not meant for that verb
- 500 with a stack trace is an information disclosure finding on its own
EOF
cat 02-status.txt

# --- 3. SMTP: the server speaks first ---
python3 - <<'PY' | tee 03-smtp.txt
import socket
try:
    with socket.create_connection(("127.0.0.1", 25), timeout=2) as s:
        s.settimeout(2)
        def rd(tag):
            d = s.recv(1024).decode("utf8","replace").strip()
            print(f"  {tag:<8} {d[:110]}")
            return d
        def wr(line, tag):
            print(f"  {tag:<8} {line}")
            s.sendall((line + "\r\n").encode())
        rd("server:")
        wr("EHLO aegis.local", "client:")
        rd("server:")
        wr("QUIT", "client:")
except OSError as e:
    print(f"  no SMTP on loopback ({type(e).__name__})")
print()
print("  Note the pattern: the SERVER sends a 220 banner unprompted. That is")
print("  why banners are such a cheap enumeration primitive - no request needed.")
PY

# --- 4. POP3 / IMAP banners, same idea ---
python3 - <<'PY' | tee 04-banners.txt
import socket
for port, label in ((110,"POP3"), (143,"IMAP"), (21,"FTP"), (23,"TELNET")):
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=1.0) as s:
            s.settimeout(1.0)
            try: banner = s.recv(128).decode("utf8","replace").strip()
            except socket.timeout: banner = "(no banner - waits for the client)"
            print(f"  {label:<7} :{port:<6} {banner[:60]}")
    except ConnectionRefusedError:
        pass
    except OSError:
        pass
PY

Step 3 is the pattern worth internalising: the server speaks first. Banners are free
information, which is why nc -v host port is the fastest enumeration you will ever run.
