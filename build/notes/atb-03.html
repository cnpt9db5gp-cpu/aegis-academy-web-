Files, Paths, Search and Text Processing

Summary

Finding things and cutting them apart. In security this means: locating files on a target,
extracting the exact fields you need from tool output, and doing it fast enough to iterate.

Key ideas

  • find with -name -type -user -perm -size -mtime -ls -exec
  • locate/updatedb versus find — index versus live walk
  • grep with -i -v -n -c -E -r -A -B
  • cut -d -f, awk '{print $N}', sort | uniq -c | sort -rn
  • sed for transforms, tr for character translation
  • Redirection and process substitution to avoid intermediate files

Terminology

Term Meaning
Glob */?/[] pattern expanded by the shell
find predicate -name, -type, -perm, -user, -size, -mtime
-exec Run a command per matched file
Field separator -d for cut/awk, FS for awk
sort -n Numeric, not lexicographic — critical for ports and sizes
uniq -c Collapse duplicates and count
tr Translate or delete characters
/dev/null Discard output
xargs Turn stdin into command arguments
updatedb Rebuild the locate database

Kali commands

# --- find, the predicates that matter in an assessment ---
find / -perm -4000 -type f 2>/dev/null | head        # SUID
find / -perm -2000 -type f 2>/dev/null | head        # SGID
find / -perm -o+w -type f 2>/dev/null | grep -v '^/proc' | head   # world-writable
find / -writable -type f -path '*/etc/*' 2>/dev/null | head
find / -user root -group root -perm -4000 2>/dev/null | head
find . -type f -size +10M -exec ls -lh {} \; 2>/dev/null | head
find . -mmin -60 -type f 2>/dev/null | head          # changed in the last hour
find / -type d -name "*backup*" 2>/dev/null | head
find /etc -type f -name "*.conf" -exec grep -l -i "password" {} \; 2>/dev/null | head

# --- locate is an index: instant but stale ---
command -v locate && (locate shadow | head -3; echo "rebuild with: sudo updatedb")

# --- grep variants ---
grep -n "PermitRootLogin" /etc/ssh/sshd_config
grep -c "Failed password" /var/log/auth.log 2>/dev/null || sudo grep -c "Failed password" /var/log/auth.log
grep -rIl "BEGIN PRIVATE KEY" ~/ 2>/dev/null | head
grep -E "^(GET|POST) " access.log | awk '{print $6, $7}' | sort | uniq -c | sort -rn | head
grep -v "^#" config.yml | grep -v '^$' | wc -l

# --- cut, awk, sort, uniq ---
cut -d: -f1,7 /etc/passwd | tail -10
awk -F: '$3 >= 1000 {print $1, $3}' /etc/passwd
awk '{print $1}' /var/log/auth.log | sort | uniq -c | sort -rn | head
sort -t/ -k1 -n ports.txt | head            # ports numerically

# --- tr and paste ---
tr '[:upper:]' '[:lower:]' < /etc/hostname
tr -d '\r' < dos-file.txt > unix-file.txt
paste <(cut -d: -f1 /etc/passwd) <(cut -d: -f7 /etc/passwd) | head

# --- xargs, space-safe and parallel ---
# Do NOT combine -n1 with -I{}. They are mutually exclusive: -I{} already
# means "one invocation per line", and GNU xargs warns
# "options --max-args and --replace are mutually exclusive" and silently
# drops one of them. Pick the mechanism, not both.
cat hosts.txt | xargs -P8 -I{} sh -c 'nmap -sT {} -oN /dev/null && echo "{} ok"'
# For plain positional batching, -n1 is right - but then you get {} by $1:
cat hosts.txt | xargs -n1 -P8 sh -c 'nmap -sT "$1" -oN /dev/null && echo "$1 ok"' _
# -print0/-0 keeps filenames with spaces and newlines intact:
find . -name "*.txt" -print0 | xargs -0 grep -l "password"

Field lab

Objective: produce an enumeration report using find/grep/awk, then confirm it in Python.

mkdir -p ~/aegis/labs/atb-03 && cd ~/aegis/labs/atb-03

# --- 1. SUID/SGID/world-writable sweep of your own machine ---
{
  echo "=== SUID ==="
  find / -perm -4000 -type f 2>/dev/null
  echo
  echo "=== SGID ==="
  find / -perm -2000 -type f 2>/dev/null | head -10
  echo
  echo "=== world-writable outside pseudo-filesystems ==="
  find / -xdev -perm -o+w -type f 2>/dev/null | grep -vE '^/(proc|sys|dev|run)' | head -15
} > 01-perms.txt
echo "wrote $(wc -l < 01-perms.txt) lines"; head -20 01-perms.txt

# --- 2. config files that mention credentials ---
{
  echo "=== readable configs mentioning 'password' ==="
  sudo find /etc /opt /srv -type f \( -name "*.conf" -o -name "*.cfg" -o -name "*.ini" -o -name "*.yaml" \) \
       2>/dev/null | head -200 | while read -r f; do
    sudo grep -li "password\|passwd\|secret\|api_key" "$f" 2>/dev/null
  done | sort -u | head -20
} 2>/dev/null | tee 02-secrets.txt

# --- 3. recently modified files: the incident-response reflex ---
find /etc /var/www /home -xdev -type f -mtime -30 2>/dev/null | head -20 | tee 03-recent.txt
echo "  (${PWD}/03-recent.txt)"

# --- 4. parse a scan: four ways to get what you need ---
nmap -sV -p- 127.0.0.1 -oN scan.txt 2>/dev/null
{
  echo "=== ports only ==="
  grep "open" scan.txt | awk -F/ '{print $1}' | sort -t/ -k1 -n | tr '\n' ' '; echo
  echo "=== services ==="
  grep "open" scan.txt | awk '{print $2}' | sort | uniq -c | sort -rn
  echo "=== service -> version ==="
  grep "open" scan.txt | awk '{print $2, $4, $5}'
  echo "=== everything, normalised ==="
  grep "open" scan.txt | sed -E 's/^([0-9]+)\/(\w+)\s+open\s+(\S+)\s*(.*)$/\1|\2|\3|\4/'
} | tee 04-parse.txt

# --- 5. awk doing real work: a small reporting pass ---
awk -F'|' '/^[0-9]/ {
    split($1, p, "/");
    printf "%-6s %-5s %-12s %s\n", $1, $2, $3, $4;
    total++
} END { printf "\n  %d open ports\n", total }' scan.txt

# --- 6. confirm with Python: same facts, different code ---
python3 - <<'PY' | tee 05-parse-python.txt
import re
rows = []
for line in open("scan.txt", errors="replace"):
    m = re.match(r"(\d+)/(tcp|udp)\s+open\s+(\S+)\s*(.*)", line)
    if m: rows.append(m.groups())
print(f"  {len(rows)} open ports")
from collections import Counter
print("  services:", dict(Counter(r[2] for r in rows)))
PY

echo
echo "Shell gave you the answer instantly; Python will scale to 10,000 hosts. Use both."

Step 1 is a real finding sheet for your own machine, and step 2 is the exact habit that turns
a foothold into root on a real engagement.

Record: 01-perms.txt and 02-secrets.txt.
