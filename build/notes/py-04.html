Lists, Dictionaries and Tuples

Summary

Two structures cover most of what you will write:

  • List — ordered, mutable sequence. For anything you iterate, sort or filter.
  • Dict — key→value mapping. For structured records and for counting.

A tuple is an immutable sequence, used for records and as dict keys.

For security, dicts represent a single finding and lists of dicts represent a scan result. Getting
that shape right early saves refactoring later.

Counting — the most common dict use

counts = {}
for line in open("log.txt", errors="replace"):
    ip = line.split()[-1]
    counts[ip] = counts.get(ip, 0) + 1

collections.Counter does it properly:

from collections import Counter, defaultdict

counts = Counter()
with open("log.txt", errors="replace") as f:
    for line in f:
        counts[line.split()[-1]] += 1
counts.most_common(10)

hosts = Counter(h for h in open("hosts.txt") if h.strip())

attempts = defaultdict(list)
attempts["10.0.0.5"].append("ssh")      # no KeyError even on first use

Tuples

target = ("10.0.0.5", 445)      # a record that must not change
port, proto = target           # unpacking

a, b = 1, 2
a, b = b, a                   # swap

seen = {}
seen[("10.0.0.5", 445)] = {"version": "Samba 4.6.2", "state": "open"}

Tuples are hashable, so they work as dict keys — which is exactly how you key a finding by
host+port.

Mutability traps

a = [1, 2, 3]
b = a            # another NAME for the same list
b.append(4)
print(a)         # [1, 2, 3, 4]  <- surprise

b = a.copy()     # or list(a), or a[:]
b.append(5)
print(a)         # [1, 2, 3, 4]

rows = [[] for _ in range(3)]     # correct: three separate lists
bad  = [[]] * 3                   # WRONG: three references to one list

Terminology

Term Meaning
List Ordered, mutable sequence
Tuple Ordered, immutable sequence
Dict Key→value mapping, insertion ordered
.get() Safe read with a default
Comprehension [expr for x in it if cond]
Aliasing Two names pointing at one mutable object
Counter Purpose-built counting from collections
defaultdict Dict that auto-creates missing keys
Hashable Can be a dict key (tuples, strings; not lists)

Field lab

Objective: build a structured finding store and hand it straight into vulnerability research.

mkdir -p ~/aegis/labs/py-04 && cd ~/aegis/labs/py-04

nmap -sV -sC -p- 127.0.0.1 -oN scan.txt -oG scan.gnmap 2>/dev/null

cat > findings.py <<'PY'
import re, sys, json, collections

PORT_RE = re.compile(
    r"^(?P<port>\d+)/(?P<proto>tcp|udp)\s+(?P<state>\S+)\s+(?P<service>\S+)(?:\s+(?P<version>.+))?$")

def parse_txt(path):
    findings = []
    with open(path, errors="replace") as f:
        for line in f:
            m = PORT_RE.match(line.rstrip())
            if not m: continue
            d = m.groupdict()
            d["port"] = int(d["port"])
            d["version"] = (d["version"] or "").strip()
            findings.append(d)
    return findings

def normalise_version(v):
    # '2.4.49 ((Debian))' -> '2.4.49'
    m = re.search(r"(\d+(?:\.\d+)+)", v or "")
    return m.group(1) if m else None

def summarise(findings):
    by_service = collections.defaultdict(list)
    by_state = collections.Counter()
    for f in findings:
        by_service[f["service"]].append(f)
        by_state[f["state"]] += 1
    versions = {f["service"]: normalise_version(f["version"])
                for f in findings if f["version"]}
    notable = [f for f in findings if f["service"] in
               ("ftp","telnet","rlogin","vnc","mysql","redis","smb","microsoft-ds")]
    return {"total_ports": len(findings), "by_state": dict(by_state),
            "versions": {k: v for k, v in versions.items() if v},
            "notable": notable}

if __name__ == "__main__":
    f = parse_txt(sys.argv[1] if len(sys.argv) > 1 else "scan.txt")
    s = summarise(f)
    print(json.dumps(s, indent=2))
    print("\n=== notable (cleartext / commonly abused) ===")
    for r in s["notable"]:
        print(f"  {r['port']:<6}{r['service']:<12}{r['version']}")

c = Counter()
try:
    for line in open("/var/log/auth.log", errors="replace"):
        if m := re.search(r"Failed password for (?:invalid user )?(\S+) from ([\d.]+)", line):
