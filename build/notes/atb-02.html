Shell Scripting and Command-Line Automation

Summary

Shell scripts are the connective tissue of security work: recon pipelines, evidence collection,
repeatable scans. This lecture covers the four things that separate a working script from a
dangerous one: strict mode, quoting, error handling, and exit codes.

Key ideas

  • #!/usr/bin/env bash and strict mode set -euo pipefail
  • Always quote expansions — "$var", never $var
  • Functions, arguments, $?, $#, $@, "$@"
  • Traps (trap) for cleanup on exit — important when a script is Ctrl+C'd mid-scan
  • Idempotence: a script you re-run should be safe
  • Logging: every real script writes where it has been and what it found

Terminology

Term Meaning
Shebang The #! interpreter line
Strict mode set -euo pipefail
Word splitting Unquoted expansions split on whitespace
Globbing */?/[] expansion by the shell
Exit status $?; 0 means success
trap Run a handler on signal or exit
Idempotent Safe to run more than once
Heredoc <<EOF inline multi-line text
Process substitution <(cmd) as a filename-like argument
mktemp Create a unique temp file safely

Kali commands

# --- the four lines every script starts with ---
cat > /tmp/skel.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
IFS=$'\n\t'
LOG="/tmp/skel-$(date +%Y%m%d-%H%M%S).log"
trap 'echo "[!] aborted at $(date -Is)" | tee -a "$LOG" >&2' EXIT INT TERM
echo "[*] started $(date -Is)" | tee -a "$LOG"
EOF
chmod +x /tmp/skel.sh && /tmp/skel.sh; rm -f /tmp/skel.sh

# --- quoting, the demonstration ---
V="two words"
echo $V; echo "$V"; echo '$V'
ls $V 2>&1 | head -1; ls "$V" 2>&1 | head -1

# --- exit codes ---
bash -c 'exit 0'; echo "0 = $?"
bash -c 'exit 3'; echo "3 = $?"
bash -c 'ls /nope' 2>/dev/null; echo "ls failure = $?"

# --- traps and signals ---
# Two things bite everyone who writes cleanup-on-interrupt, and both are
# demonstrated below rather than asserted.
echo "=== 1. job control ON: SIGINT reaches the job, the trap fires ==="
set -m
bash -c 'trap "echo \"  CAUGHT SIGINT\"" INT; sleep 5' &
sleep 0.3; kill -INT %1; wait
set +m

echo "=== 2. job control OFF: the SAME SIGINT is silently ignored ==="
bash -c 'trap "echo \"  CAUGHT SIGINT\"" INT; sleep 2' &
sleep 0.3; kill -INT %1; wait
echo "  ^ nothing printed. A background job in a non-interactive shell has"
echo "    SIGINT set to ignore, so the trap is never even reached. This is"
echo "    why a scripted 'send it Ctrl+C' test silently proves nothing."

echo "=== 3. a trap fires BETWEEN commands, never during one ==="
bash -c 'trap "echo \"  CAUGHT TERM\"" TERM; sleep 2' &
sleep 0.3; kill -TERM %1; wait
echo "  ^ that took ~2s, not 0.3s. The shell was sitting on the child, so"
echo "    the handler waited for its turn. Long-running children are why"
echo "    cleanup handlers can appear to hang."

# --- safe temp files ---
mktemp -d
mktemp --tmpdir probe.XXXXXX

# --- argument handling ---
cat > args.sh <<'EOF'
#!/usr/bin/env bash
echo "  argc   : $#"
echo "  all    : $*"
for a in "$@"; do echo "  arg    : $a"; done
EOF
chmod +x args.sh && ./args.sh "one two" three
rm -f args.sh

Field lab

Objective: write a production-quality reconnaissance script with strict mode, a scope guard,
traps, logging and meaningful exit codes.

mkdir -p ~/aegis/labs/atb-02 && cd ~/aegis/labs/atb-02

cat > recon.sh <<'EOF'
#!/usr/bin/env bash
#
# recon.sh - scoped host discovery for an authorised lab network.
# Usage: ./recon.sh <cidr>
# Exit:  0 ok | 2 usage | 3 out of scope | 4 no hosts found
#
set -euo pipefail
IFS=$'\n\t'

usage() { echo "usage: $0 <cidr or ip>" >&2; exit 2; }

in_scope() {
  case "$1" in
    127.*|192.168.*|10.*|172.1[6-9].*|172.2[0-9].*|172.3[01].*) return 0 ;;
    *) return 1 ;;
  esac
}

[[ $# -ge 1 ]] || usage
TARGET="$1"
in_scope "$TARGET" || { echo "REFUSING $TARGET: outside RFC1918/loopback. See docs/RULES-OF-ENGAGEMENT.md" >&2; exit 3; }

command -v nmap >/dev/null || { echo "nmap not installed" >&2; exit 5; }

STAMP=$(date +%Y%m%d-%H%M%S)
OUT="$HOME/aegis/labs/atb-02/recon-$STAMP"
mkdir -p "$OUT"
LOG="$OUT/run.log"

log() { printf '[%s] %s\n' "$(date +%H:%M:%S)" "$*" | tee -a "$LOG"; }

cleanup() { log "finished, artefacts in $OUT"; }
trap cleanup EXIT
trap 'log "interrupted"; exit 130' INT TERM

log "scanning $TARGET"
nmap -sn "$TARGET" -oN "$OUT/hosts.txt" 2>/dev/null \
  | grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' | sort -u > "$OUT/alive.txt" || true

COUNT=$(wc -l < "$OUT/alive.txt")
log "$COUNT host(s) alive"

if [[ "$COUNT" -eq 0 ]]; then
  log "nothing alive - is the lab network up? (see docs/LAB-SETUP.md)"
  exit 4
fi

while read -r host; do
  [[ -z "$host" ]] && continue
  log "scanning $host"
  nmap -sT --top-ports 100 -T4 "$host" -oN "$OUT/$host.txt" 2>/dev/null || log "  scan of $host failed, continuing"
done < "$OUT/alive.txt"

{
  echo "RECON SUMMARY  $(date -Is)"
  echo "target: $TARGET   hosts: $COUNT"
  for f in "$OUT"/*.txt; do
    [[ "$(basename "$f")" == "run.log" ]] && continue
    [[ "$(basename "$f")" == "alive.txt" ]] && continue
    [[ "$(basename "$f")" == "hosts.txt" ]] && continue
    echo
    echo "=== $(basename "$f" .txt) ==="
    grep -E "open|filtered" "$f" || echo "  (no open ports in the top 100)"
  done
} > "$OUT/SUMMARY.txt"

log "summary written"
echo "  $OUT/SUMMARY.txt"
exit 0
EOF
chmod +x recon.sh

echo "=== usage error ==="; ./recon.sh; echo "  exit=$? (expect 2)"
echo "=== scope guard ==="; ./recon.sh 8.8.8.8; echo "  exit=$? (expect 3)"
echo "=== loopback, nothing alive ==="; ./recon.sh 127.0.0.0/30; echo "  exit=$? (expect 4)"
echo "=== your lab range, if built ==="; ./recon.sh 192.168.56.0/24 2>&1 | tail -6; echo "  exit=$?"
echo
echo "=== the artefacts ==="
ls -la ~/aegis/labs/atb-02/recon-*/ | head -12
cat ~/aegis/labs/atb-02/recon-*/SUMMARY.txt 2>/dev/null | head -20

echo
echo "=== shellcheck it, if available ==="
command -v shellcheck >/dev/null && shellcheck recon.sh || echo "(sudo apt install shellcheck to lint it)"

Three things in that script matter more than the scanning: the RFC1918 guard (it cannot
scan outside your lab), the traps (Ctrl+C still leaves you a clean artefact directory and an
honest log), and the exit codes (so recon.sh lab && notify behaves).
