TCP, UDP and the Three-Way Handshake

Summary

Transport layer: ports, connection state, reliability. This lecture is where scanning becomes
predictable, because nmap's scan types and every network service's behaviour are direct
consequences of how TCP establishes, uses, and tears down a connection.

Key ideas

  • Three-way handshake: SYN → SYN/ACK → ACK. This is why state exists and why SYN scanning works
  • Four-way FIN teardown, RST for immediate abort
  • Half-open: a SYN scan never completes the handshake, so the server logs little
  • Sequence numbers: 32-bit, per-direction. The basis of TCP sequence prediction attacks
  • UDP has no handshake — no state, no guarantee. Scanning UDP is slow and unreliable
  • Ports: 0-1023 well-known, 1024-49151 registered, 49152-65535 ephemeral
  • Time-wait exists to make sequence numbers unique

Terminology

Term Meaning
SYN Synchronise — start a connection
ACK Acknowledge
FIN Finish — orderly close
RST Reset — abortive close
Three-way handshake SYN, SYN/ACK, ACK
Half-open SYN sent, handshake never completed
Sequence number Per-byte position counter
Time-wait 2MSL delay after close, to avoid old packets
Ephemeral port Client-side temporary port
MTU Largest payload a link will carry

# --- 2. read it back, with the states made explicit ---
{
  echo "=== the conversation, flag by flag ==="
  sudo tcpdump -i lo -n -r 01-handshake.pcap 2>/dev/null | head -20
  echo
  echo "=== annotations ==="
  cat <<'EOF'
  1. SYN           client wants to connect, sends its initial sequence number (ISN)
  2. SYN,ACK       server agrees, replies with its own ISN, ACKs yours
  3. ACK           client acknowledges; connection is now ESTABLISHED
  4. PSH,ACK       actual payload, pushed immediately
  5. FIN,ACK       orderly close from one side
  6. FIN,ACK       the other side closes too
  7. ACK           final acknowledgement; both sides enter TIME_WAIT
EOF
} | tee 02-annotated.txt

# --- 3. the state machine, as this host sees it ---
{
  echo "=== connection states right now ==="
  ss -tan | awk 'NR>1{print $1}' | sort | uniq -c | sort -rn
  echo
  echo "=== TCP counters from /proc/net/snmp ==="
  grep -A1 "^Tcp:" /proc/net/snmp | head -2 | tail -1 | tr ' ' '\n' | \
    grep -iE "attempt|estab|listen|retrans" | head -8
} 2>&1 | tee 03-states.txt

# --- 4. the same thing, but with SYN only (half-open) ---
python3 - <<'PY' | tee 04-synonly.txt
import socket, struct, time

def syn_only(host, port):
    """Open a raw socket and send only a SYN. Never complete the handshake."""
    s = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_TCP)
    s.setsockopt(socket.IPPROTO_TCP, socket.IP_TTL, 64)
    seq = 1000
    src_port = 40000
    flags = 0x02                        # SYN
    pseudo = socket.inet_aton(host) + socket.inet_aton("127.0.0.1")
    pseudo += struct.pack(">H", src_port) + struct.pack(">H", port) + struct.pack(">I", seq)
    pseudo += b"\x00" * 8 + struct.pack("!BBH", (5 << 4), flags, 65535)
    check = sum(struct.unpack("!%dH" % (len(pseudo)//2), pseudo))
    check = (check >> 16) + (check & 0xFFFF); check += check >> 16
    check = ~check & 0xFFFF
    tcp = struct.pack("!HHIIBBHHH", src_port, port, seq, 0, (5<<4), flags, 65535, check, 0)
    s.sendto(struct.pack("!BBHHHBBH", 0x45, 0, 40+20, 0, 64, 6, 64, 0) +
             socket.inet_aton("127.0.0.1") + socket.inet_aton(host) + tcp,
             (host, port))
    s.close()
    return "SYN sent, handshake NOT completed"

print("  ", syn_only("127.0.0.1", 9002))
print("  A SYN scan leaves the server with a half-open connection and far less logging.")
print("  A connect scan (-sT) completes the handshake and is fully logged.")

# --- 6. UDP has no handshake ---
python3 - <<'PY' | tee 06-udp.txt
import socket
for port in (53, 123, 161, 500, 1900):
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    s.settimeout(1.0)
    try:
        s.sendto(b"\x00", ("127.0.0.1", port))
        data, addr = s.recvfrom(1024)
        print(f"  {port:<6} replied {len(data)} bytes -> OPEN or filtered-but-responding")
    except socket.timeout:
        print(f"  {port:<6} no reply -> CLOSED or FILTERED (indistinguishable)")
    except OSError as e:
        print(f"  {port:<6} {type(e).__name__}")
    finally: s.close()
print()
print("This ambiguity is why nmap reports UDP ports as 'open|filtered'.")
