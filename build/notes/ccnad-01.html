OSI, TCP/IP and Encapsulation in Depth

Summary

The two reference models, and what encapsulation actually does to your data on the way out and
back in. Depth matters here because it is the shared vocabulary for every protocol conversation
you will ever have about a network problem or an attack.

Key ideas

  • OSI: 7 layers — Physical, Data Link, Network, Transport, Session, Presentation, Application
  • TCP/IP: 4 layers — Link, Internet, Transport, Application
  • Encapsulation: each layer prepends its header; the receiver strips in reverse
  • PDU names: bits, frames, packets, segments/datagrams, data
  • Session/Presentation have no separate existence in TCP/IP — the transport and app layers
    absorbed them (TLS lives roughly where Presentation would; TLS session tickets cover Session)
  • MTU and fragmentation happen at Layer 3; fragmentation is expensive and often avoided

Terminology

Term Meaning
Encapsulation Wrapping data with layer headers
Decapsulation Stripping headers on receipt
PDU Protocol Data Unit; the unit at each layer
MTU Maximum Transmission Unit per link
Fragmentation Splitting a packet larger than the path MTU
Header Layer metadata prepended to the payload
Ports Transport-layer endpoint identifier
Sockets The kernel object combining all of the above

echo "  1472 works and 1473 fails: that is exactly the 1500 MTU minus 20 IP minus 8 ICMP header"

# --- build an Ethernet frame by hand and read it back ---
python3 - <<'PY'
import struct
def ether(dst, src, ethertype, payload):
    return (bytes.fromhex(dst.replace(':','')) + bytes.fromhex(src.replace(':',''))
            + struct.pack(">H", ethertype) + payload)
def ipv4(src, dst, proto, payload):
    total = 20 + len(payload)
    hdr = struct.pack("!BBHHHBBH4s4s", 0x45, 0, total, 0x1234, 0, 64, proto, 0,
                      bytes(map(int, src.split('.'))), bytes(map(int, dst.split('.'))))
    return hdr + payload
frame = ether("ff:ff:ff:ff:ff:ff", "00:11:22:33:44:55", 0x0800,
              ipv4("192.168.1.10", "192.168.1.1", 1, b"ping-payload"))
print(f"  frame length   : {len(frame)} bytes")
print(f"  dst MAC        : {frame[0:6].hex(':')}")
print(f"  src MAC        : {frame[6:12].hex(':')}")
print(f"  ethertype      : 0x{frame[12:14].hex()} (0x0800 = IPv4)")
print(f"  IP version/ihl : {frame[14] >> 4} / {frame[14] & 0xF}")
print(f"  total length   : {struct.unpack('!H', frame[16:18])[0]}")
print(f"  TTL            : {frame[22]}")
print(f"  protocol       : {frame[23]} (1 = ICMP)")

Field lab

Objective: decode a real packet by hand, layer by layer, and confirm each field with a tool.

mkdir -p ~/aegis/labs/ccnad-01 && cd ~/aegis/labs/ccnad-01

# --- 1. capture one packet ---
sudo timeout 10 tcpdump -i lo -n -c 3 -X "icmp" 2>/dev/null | tee 01-xxd.txt
echo
echo "Each line shows 16 bytes: offset, hex, then ASCII."
echo "Walk it: 6 bytes dst MAC | 6 src | 2 type | 20 IP header | ... payload"

# --- 2. the same packet, annotated by tshark ---
command -v tshark
if command -v tshark >/dev/null; then
  sudo timeout 12 tshark -i lo -c 4 -V "icmp" 2>/dev/null | head -40 | tee 02-tshark.txt
  echo "tshark -V prints every layer separately. Compare with 01-xxd.txt."
fi

# --- 3. MTU and fragmentation, proven ---
{
  echo "=== interface MTUs ==="
  for i in /sys/class/net/*/mtu; do echo "  $(basename $(dirname $i)): $(cat $i)"; done
  echo
  echo "=== payload size that still fits with DF set ==="
  for sz in 1472 1473 1474; do
    r=$(ping -c1 -W1 -M do -s $sz 8.8.8.8 2>&1 | grep -c "frag needed\|error")
    echo "  -s $sz : $([ "$r" -gt 0 ] && echo TOO BIG || echo ok)"
  done
  echo
  echo "1500 MTU - 20 (IP) - 8 (ICMP) = 1472. That arithmetic is the whole test."
} 2>&1 | tee 03-mtu.txt

# --- 4. encapsulation, seen as bytes ---
python3 - <<'PY' | tee 04-encap.txt
import struct, binascii
payload = b"GET / HTTP/1.1\r\nHost: x\r\n\r\n"
tcp = struct.pack("!HHIIBBHHH", 1234, 80, 1, 0, (5 << 4), 0x18, 8192, 0, 0) + payload
ip  = struct.pack("!BBHHHBBH4s4s", 0x45, 0, 20+len(tcp), 0x1, 0, 64, 6, 0,
                  bytes([192,168,1,10]), bytes([192,168,1,1]))
eth = bytes.fromhex("aabbccddeeff") + bytes.fromhex("112233445566") + struct.pack(">H", 0x0800) + ip
tcp_full = eth + tcp
print(f"  application payload : {len(payload)} bytes")
print(f"  + TCP header        : {len(tcp)} bytes (20 header + {len(payload)} payload)")
print(f"  + IP header         : {len(ip)} bytes")
print(f"  + Ethernet header   : {len(eth)} bytes (14 header + {len(ip)} IP)")
print(f"  on the wire         : {len(tcp_full)} bytes")
print()
print("  first 42 bytes as sent:")
print("   ", tcp_full[:42].hex(" "))
print("  layer boundaries:")
print("   ", eth[:14].hex(" "), " <- Ethernet")
print("   ", eth[14:34].hex(" "), " <- IP")
print("   ", eth[34:54].hex(" "), " <- TCP")
print("   ", eth[54:].hex(" ") or "(payload starts here)")

# OSI vs TCP/IP

| # | OSI | TCP/IP | PDU | Devices | Example protocol |
|---|---|---|---|---|---|
| 7 | Application | Application | Data | hosts | HTTP, DNS, SSH |
| 6 | Presentation | (in app) | Data | - | TLS, JPEG |
| 5 | Session | (in app) | Data | - | TLS sessions |
| 4 | Transport | Transport | Segment/Datagram | - | TCP, UDP |
| 3 | Network | Internet | Packet | routers | IP, ICMP, OSPF |
| 2 | Data Link | Link | Frame | switches | Ethernet, ARP |
| 1 | Physical | Link | Bits | hubs, cables | 1000BASE-T |

Security roles:
- L2: ARP spoofing, MAC flooding, evil twin
- L3: spoofing, routing attacks, IP fragmentation attacks
- L4: SYN flood, session hijacking, sequence prediction
- L7: everything in Tier 4
EOF
